## Phase 2 carry-over

- **Punch list item 33** — Inspection two-step model. The reviewer suggests a clearer two-step model (create as PENDING → `recordOutcome()` with FOR UPDATE that refuses non-PENDING). Recommendation-class because the service exposes no UPDATE method today, so the immutable invariant already holds. Lands pre-pilot as a consistency improvement aligning with the Cycle 11 SessionNoteService.lock + Cycle 16 ApplicationStageService patterns.
