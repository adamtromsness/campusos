P2-28: Community .1 Bundle

The largest remaining cycle bundles deferred tables from four community modules: Groups & Communities (M103) with polls, group events, resource sharing, and engagement analytics; Clubs & Student Life (M64) with student elections, club budgets, field trip evaluation, and service partner organisations; Meetings (M41) with structured agendas, action items, AI meeting minutes, and recording consent management; and Student Services (M27) with counsellor caseload management, agency referrals, and longitudinal wellbeing tracking. Pre-split into 3 sub-cycles.
May 2026 · 3 Sub-Cycles · ERD v11 · M103.1 + M64.1 + M41.1 + M27.1 (27 tables) · GRP-001..003 + CLB-001..004 + MTG-001..002 + SVC-001..003 · Phase 2 Cycle 28

Sub-Cycle Structure

27 tables across 4 modules, split along module boundaries for clean dependency management.

P2-28a — Groups Advanced (9 tables)

Group polls with multi-option voting and results aggregation, group events with RSVP management (distinct from school-wide P2-12 events), group resource library with file sharing and version control, group invitations with approval workflow, and group engagement analytics (posts, comments, active members per period).

P2-28b — Clubs + Meetings Advanced (10 tables)

Student government elections with anonymous voting (structurally anonymous: ext_votes has NO voter_id column; ext_election_voter_check records WHO voted without linking to HOW), club budget management with transaction tracking, field trip post-evaluation, service learning partner organisations; meeting agenda items with timed presenters, meeting action items with assignee tracking, AI-generated meeting minutes (stub), meeting templates for recurring meeting types.

P2-28c — Student Services Advanced (8 tables)

Counsellor caseload management with capacity tracking and auto-assignment, formal referral workflow (teacher → counsellor → external provider) with immutable activity log, referral type configuration, external agency referrals for outside-school services, longitudinal wellbeing tracking across academic years, MTSS team meeting coordination, and intervention effectiveness reporting.

P2-28a: Groups Advanced (M103.1)

01Schema (9 tables)
Schema
  1. grp_group_polls — group_id UUID FK NOT NULL, question TEXT NOT NULL, poll_type TEXT NOT NULL 3-value CHECK (SINGLE_CHOICE, MULTIPLE_CHOICE, RANKED), allows_anonymous BOOLEAN DEFAULT false, closes_at TIMESTAMPTZ, status TEXT NOT NULL DEFAULT 'OPEN' 3-value CHECK (OPEN, CLOSED, CANCELLED), created_by UUID FK NOT NULL. INDEX(group_id, status).
  2. grp_poll_options — poll_id UUID FK NOT NULL, option_text TEXT NOT NULL, sort_order INT NOT NULL, vote_count INT DEFAULT 0. UNIQUE(poll_id, sort_order).
  3. grp_poll_votes — poll_id UUID FK NOT NULL, option_id UUID FK NOT NULL, voter_id UUID FK (NULL when allows_anonymous=true), rank INT (for RANKED polls). UNIQUE(poll_id, voter_id, option_id) WHERE voter_id IS NOT NULL. Atomic: UPDATE grp_poll_options SET vote_count = vote_count + 1.
  4. grp_group_events — group_id UUID FK NOT NULL, title TEXT NOT NULL, description TEXT, event_date TIMESTAMPTZ NOT NULL, location TEXT, max_attendees INT, created_by UUID FK NOT NULL. INDEX(group_id, event_date). Distinct from evt_events (P2-12) — these are informal group-level meetups, not school-wide ticketed events.
  5. grp_event_rsvps — event_id UUID FK NOT NULL, member_id UUID FK NOT NULL, status TEXT NOT NULL DEFAULT 'PENDING' 3-value CHECK (CONFIRMED, DECLINED, PENDING), responded_at TIMESTAMPTZ. UNIQUE(event_id, member_id). CHECK(confirmed count ≤ max_attendees) enforced at service layer.
  6. grp_resource_library — group_id UUID FK NOT NULL, title TEXT NOT NULL, description TEXT, resource_type TEXT NOT NULL 5-value CHECK (DOCUMENT, LINK, IMAGE, VIDEO, TEMPLATE), s3_key TEXT, url TEXT, uploaded_by UUID FK NOT NULL, version INT DEFAULT 1, is_pinned BOOLEAN DEFAULT false. INDEX(group_id, is_pinned DESC, created_at DESC).
  7. grp_resource_versions — resource_id UUID FK NOT NULL, version_number INT NOT NULL, s3_key TEXT, uploaded_by UUID FK NOT NULL, change_notes TEXT. UNIQUE(resource_id, version_number). On new version: grp_resource_library.version incremented.
  8. grp_group_invitations — group_id UUID FK NOT NULL, invited_user_id UUID FK NOT NULL, invited_by UUID FK NOT NULL, status TEXT NOT NULL DEFAULT 'PENDING' 3-value CHECK (PENDING, ACCEPTED, DECLINED), message TEXT. UNIQUE(group_id, invited_user_id). On ACCEPTED: creates grp_group_members row.
  9. grp_group_analytics — group_id UUID FK NOT NULL, period DATE NOT NULL (monthly), total_members INT, active_members INT, posts_count INT, comments_count INT, polls_created INT, events_held INT, resources_shared INT, engagement_rate NUMERIC(5,4). UNIQUE(group_id, period). Materialised monthly by GroupAnalyticsWorker.
Produces → 9 tables. Migration: 159_grp_polls_events_resources.sql.

P2-28b: Clubs + Meetings Advanced (M64.1 + M41.1)

03Schema (10 tables)
Schema
  1. ext_elections — school_id UUID NOT NULL, title TEXT NOT NULL, description TEXT, voting_start TIMESTAMPTZ NOT NULL, voting_end TIMESTAMPTZ NOT NULL, eligible_voters_filter JSONB NOT NULL (e.g., {grade_levels: ["9","10","11","12"]}), status TEXT NOT NULL DEFAULT 'DRAFT' 4-value CHECK (DRAFT, OPEN, CLOSED, RESULTS_PUBLISHED), created_by UUID FK NOT NULL. INDEX(school_id, status).
  2. ext_candidates — election_id UUID FK NOT NULL, student_id UUID FK NOT NULL, position TEXT NOT NULL, statement TEXT, photo_s3_key TEXT, is_approved BOOLEAN DEFAULT true. UNIQUE(election_id, student_id, position).
  3. ext_votes — election_id UUID FK NOT NULL, position TEXT NOT NULL, candidate_id UUID FK NOT NULL, voted_at TIMESTAMPTZ NOT NULL. NO voter_id column — anonymity is structural. Cannot reverse-engineer who voted for whom.
  4. ext_election_voter_check — election_id UUID FK NOT NULL, student_id UUID FK NOT NULL. PRIMARY KEY(election_id, student_id). Records WHO voted without linking to HOW they voted. Prevents double voting.
  5. ext_club_budgets — activity_id UUID FK(ext_activities) NOT NULL, academic_year_id UUID FK NOT NULL, allocated_amount NUMERIC(10,2) NOT NULL, spent_amount NUMERIC(10,2) DEFAULT 0, remaining_amount NUMERIC(10,2) (computed: allocated - spent), approved_by UUID FK. UNIQUE(activity_id, academic_year_id).
  6. ext_budget_transactions — budget_id UUID FK NOT NULL, transaction_type TEXT NOT NULL 4-value CHECK (ALLOCATION, EXPENSE, REFUND, ADJUSTMENT), amount NUMERIC(10,2) NOT NULL, description TEXT NOT NULL, receipt_s3_key TEXT, recorded_by UUID FK NOT NULL. INDEX(budget_id, created_at DESC). On INSERT: updates ext_club_budgets.spent_amount.
  7. ext_field_trip_evaluations — field_trip_id UUID FK(ext_field_trips) NOT NULL, evaluated_by UUID FK NOT NULL, overall_rating INT NOT NULL CHECK(1..5), educational_value_rating INT CHECK(1..5), logistics_rating INT CHECK(1..5), safety_rating INT CHECK(1..5), comments TEXT, would_recommend BOOLEAN. UNIQUE(field_trip_id, evaluated_by).
  8. ext_service_partner_orgs — school_id UUID NOT NULL, org_name TEXT NOT NULL, contact_name TEXT, contact_email TEXT, contact_phone TEXT, service_types TEXT[], is_active BOOLEAN DEFAULT true. UNIQUE(school_id, org_name). Service learning partner organisations for student volunteer placement.
  9. mtg_meeting_templates — school_id UUID NOT NULL, name TEXT NOT NULL, meeting_type_id UUID FK(mtg_meeting_types), default_duration_minutes INT, default_agenda JSONB (pre-populated agenda items), created_by UUID FK NOT NULL. UNIQUE(school_id, name).
  10. mtg_ai_minutes — meeting_id UUID FK(mtg_meetings) NOT NULL UNIQUE, raw_transcript TEXT, ai_summary TEXT, ai_action_items JSONB (extracted action items with assignee suggestions), ai_key_decisions JSONB, model_version TEXT, generated_at TIMESTAMPTZ, status TEXT NOT NULL DEFAULT 'PENDING' 3-value CHECK (PENDING, GENERATED, APPROVED), approved_by UUID FK. AI Inference stub — generates placeholder until P3-A1.
Produces → 10 tables. Migration: 160_ext_elections_budgets_mtg.sql.

P2-28c: Student Services Advanced (M27.1)

05Schema (8 tables)
Schema
  1. svc_counsellor_caseloads — counselor_id UUID FK(hr_employees) NOT NULL, student_id UUID FK(sis_students) NOT NULL, school_id UUID NOT NULL, academic_year_id UUID FK NOT NULL, assigned_at TIMESTAMPTZ NOT NULL, status TEXT NOT NULL DEFAULT 'ACTIVE' 3-value CHECK (ACTIVE, TRANSFERRED, GRADUATED). UNIQUE(counselor_id, student_id, academic_year_id) WHERE status='ACTIVE'. INDEX(counselor_id, status). INDEX(student_id).
  2. svc_referral_types — school_id UUID NOT NULL, name TEXT NOT NULL, referral_category TEXT NOT NULL 3-value CHECK (INTERNAL, EXTERNAL, CRISIS), default_priority TEXT DEFAULT 'MEDIUM' 4-value CHECK (LOW, MEDIUM, HIGH, URGENT), requires_parent_notification BOOLEAN DEFAULT true, is_active BOOLEAN DEFAULT true. UNIQUE(school_id, name).
  3. svc_referrals — school_id UUID NOT NULL, student_id UUID FK NOT NULL, referral_type_id UUID FK NOT NULL, referred_by UUID FK NOT NULL, assigned_to_id UUID FK (counsellor), priority TEXT NOT NULL, concern_description TEXT NOT NULL, status TEXT NOT NULL DEFAULT 'PENDING' 6-value CHECK (PENDING, ACCEPTED, IN_PROGRESS, RESOLVED, CLOSED, DECLINED), source_incident_id UUID (SOFT INTEGRITY → sis_discipline_incidents), parent_notified BOOLEAN DEFAULT false, parent_notified_at TIMESTAMPTZ. INDEX(student_id, status). INDEX(assigned_to_id, status). Emits svc.referral.created.
  4. svc_referral_activity — IMMUTABLE. referral_id UUID FK NOT NULL, actor_id UUID FK NOT NULL, activity_type TEXT NOT NULL 6-value CHECK (STATUS_CHANGE, ASSIGNMENT_CHANGE, NOTE_ADDED, PARENT_NOTIFIED, ESCALATED, EXTERNAL_CONTACT_MADE), notes TEXT. NO UPDATE, NO DELETE.
  5. svc_agency_referrals — referral_id UUID FK(svc_referrals) NOT NULL, agency_name TEXT NOT NULL, agency_contact TEXT, agency_phone TEXT, agency_email TEXT, referral_date DATE NOT NULL, reason TEXT NOT NULL, status TEXT NOT NULL DEFAULT 'REFERRED' 4-value CHECK (REFERRED, CONTACTED, ACTIVE_SERVICE, DISCHARGED), consent_obtained BOOLEAN DEFAULT false, follow_up_date DATE. INDEX(referral_id). External agency for outside-school services (therapy, social services, etc.).
  6. svc_wellbeing_longitudinal — student_id UUID FK NOT NULL, school_id UUID NOT NULL, academic_year TEXT NOT NULL, domain TEXT NOT NULL 5-value CHECK (ACADEMIC, SOCIAL, EMOTIONAL, PHYSICAL, SAFETY), avg_score NUMERIC(3,1), trend TEXT NOT NULL 3-value CHECK (IMPROVING, STABLE, DECLINING), checkin_count INT, flagged_count INT, counsellor_notes TEXT. UNIQUE(student_id, academic_year, domain). Materialised annually from svc_wellbeing_check_in_responses. Multi-year view of student wellbeing.
  7. svc_mtss_team_meetings — school_id UUID NOT NULL, meeting_id UUID (SOFT INTEGRITY → mtg_meetings), academic_year_id UUID FK NOT NULL, facilitated_by UUID FK NOT NULL, meeting_date DATE NOT NULL, notes TEXT. INDEX(school_id, meeting_date DESC). Links formal MTSS team review meetings to the students discussed.
  8. svc_mtss_meeting_students — team_meeting_id UUID FK NOT NULL, student_id UUID FK NOT NULL, tier_id UUID FK(svc_mtss_tiers), discussion_notes TEXT, tier_change_recommended TEXT 3-value CHECK (MAINTAIN, ESCALATE, DE_ESCALATE) nullable, action_items JSONB. UNIQUE(team_meeting_id, student_id). Junction table: which students were discussed at which MTSS meeting.
Produces → 8 tables. Migration: 161_svc_caseloads_referrals.sql. Total P2-28 tables: 27.
