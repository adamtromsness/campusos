P2-H1: Security & Access Control

Closes all data access vulnerabilities. After this cycle, no endpoint can leak cross-school data, no student-owned record can be modified by non-owners, and custody-aware filtering is centralised.

01Integration Test Pyramid — Critical Path (Target: ≥80% coverage)

Code Cat 8 — 28 modules at 0%

Priority tiers based on risk. Each module needs integration tests covering: happy path, error path, permission enforcement, school-scope isolation, and edge cases.

  1. Tier 1 — Financial (must reach ≥95%): finance (GL posting, journal batches, budget transfers), payments (invoices, payments, refunds, credit notes, reversals, payment plans, lunch accounts, financial aid), payroll (wage processing), procurement (POs, budget commitments, receiving).
  2. Tier 2 — Auth & Security (must reach ≥95%): iam (permission resolution, role assignments, effective access cache), auth (login, JWT refresh, tenant resolution, MFA).
  3. Tier 3 — Atomic Operations (must reach ≥95%): ticket sales (concurrent race test), conference booking (atomic slot), gate scanning (double-scan), gift card redemption (concurrent), budget transfer (deadlock-safe), promotion max_uses, journal batch balance validation.
  4. Tier 4 — IMMUTABLE Contracts (must reach 100%): CI test per IMMUTABLE table: attempt UPDATE → failure. Attempt DELETE → failure. Verify trigger fires.
  5. Tier 5 — Core Domain (≥80%): sis, enrollment, attendance, classroom, scheduling, hr, messaging, notifications, curriculum, discipline, wellbeing, counselling.
  6. Tier 6 — Operational (≥80%): store, facilities, transport, food-service, library, athletics, clubs, groups, meetings, governance, analytics, platform, configuration, announcements, profile, households, region, workflows, tickets.
Produces → All critical-path modules ≥95%. All other modules ≥80%. Global coverage ≥80%.
