P2-7: Classroom Advanced

Hall passes with configurable limits and location tracking, rubrics engine with weighted criteria and per-criterion scoring, standards-based gradebook with evidence linking, peer review assignments with anonymised feedback, AI tutoring sessions with conversation history and learning signal extraction, lesson video recording with transcription pipeline and AI-generated summaries, and class moments photo sharing. The highest teacher-engagement feature set in CampusOS. Pre-split into 3 sub-cycles.
May 2026 · 3 Sub-Cycles · ERD v11 · M21 Classroom .1 (24 tables) · ATT-005 + TCH-001..009 · Phase 2 Cycle 7

Sub-Cycle Structure

24 tables is too large for a single Claude Code session. This cycle is pre-split into 3 independently shippable sub-cycles. Each has its own schema, seed, services, UI, tests, and commit. Dependencies flow forward: P2-7a has none, P2-7b extends the gradebook, P2-7c requires the AI Inference extracted service.

P2-7a — Hall Passes + Rubrics + Class Moments (8 tables)

Teacher daily ops: digital hall passes with configurable limits + destination tracking, rubrics engine with weighted criteria + per-submission scoring, class moments photo feed for families. No external service dependencies. Ship immediately.

P2-7b — Standards Gradebook + Peer Review (8 tables)

Assessment depth: standards-based gradebook with per-standard evidence linking (extends Cycle 23 cur_standards), peer review assignments with anonymised feedback + rubric-based scoring, student progress notes, report card subjects. No external service dependencies.

P2-7c — AI Tutoring + Lesson Video (8 tables)

AI-powered features: AI tutoring sessions with conversation history + learning signal extraction for counsellors, lesson video recording with S3 upload + transcription pipeline + AI-generated summaries, AI usage logging with per-tenant quota enforcement. Requires AI Inference + Video Processing extracted services.

P2-7a: Hall Passes + Rubrics + Class Moments

01Schema (8 tables)
Schema
  1. cls_hall_pass_settings — school_id UUID UNIQUE, max_concurrent_passes_per_class INT DEFAULT 3, max_daily_passes_per_student INT DEFAULT 5, default_duration_minutes INT DEFAULT 10, destinations TEXT[] DEFAULT '{"Bathroom","Nurse","Office","Library","Other"}', require_teacher_approval BOOLEAN DEFAULT true.
  2. cls_hall_passes — school_id UUID, student_id UUID FK NOT NULL, class_id UUID FK NOT NULL, issued_by UUID FK NOT NULL (teacher), destination TEXT NOT NULL, issued_at TIMESTAMPTZ NOT NULL, expected_return_at TIMESTAMPTZ NOT NULL, returned_at TIMESTAMPTZ nullable, status TEXT NOT NULL DEFAULT 'ACTIVE' 4-value CHECK (ACTIVE, RETURNED, OVERDUE, RECALLED). INDEX(school_id, status) WHERE status='ACTIVE'. INDEX(student_id, issued_at DESC). Emits cls.hall_pass.issued + cls.hall_pass.overdue (when expected_return_at passes without return).
  3. cls_rubrics — school_id UUID, created_by UUID FK, title TEXT NOT NULL, description TEXT, is_template BOOLEAN DEFAULT false (template rubrics shared across assignments), total_points NUMERIC(6,2). INDEX(school_id, created_by).
  4. cls_rubric_criteria — rubric_id UUID FK NOT NULL, criterion_name TEXT NOT NULL, description TEXT, weight NUMERIC(5,2) NOT NULL (% of total; SUM per rubric should = 100), max_points NUMERIC(5,2) NOT NULL, sort_order INT NOT NULL, performance_levels JSONB (array of {level_name, description, points}: e.g., [{Excellent, 10}, {Good, 8}, {Developing, 5}, {Beginning, 2}]). INDEX(rubric_id, sort_order).
  5. cls_rubric_scores — submission_id UUID FK(cls_submissions) NOT NULL, criterion_id UUID FK NOT NULL, scored_by UUID FK NOT NULL (teacher or peer), points_awarded NUMERIC(5,2) NOT NULL, performance_level TEXT, feedback TEXT. UNIQUE(submission_id, criterion_id, scored_by). INDEX(submission_id).
  6. cls_class_moments — class_id UUID FK NOT NULL, posted_by UUID FK NOT NULL (teacher), caption TEXT, posted_at TIMESTAMPTZ NOT NULL, is_approved BOOLEAN DEFAULT true (auto-approved for teachers; student-posted moments require approval if enabled). INDEX(class_id, posted_at DESC).
  7. cls_class_moment_photos — moment_id UUID FK NOT NULL, s3_key TEXT NOT NULL, sort_order INT DEFAULT 0. INDEX(moment_id).
  8. cls_class_moment_reactions — moment_id UUID FK NOT NULL, reacted_by UUID FK NOT NULL, reaction_type TEXT NOT NULL DEFAULT 'LIKE' 3-value CHECK (LIKE, LOVE, CELEBRATE). UNIQUE(moment_id, reacted_by).
Produces → 8 tables. Migration: 112_cls_hall_rubric_moments.sql.

  4. Class Moments Feed /classroom/classes/:id/moments — photo timeline. Teacher: post with caption + multi-photo upload. Parent: view + react. Instagram-lite for classrooms.

P2-7b: Standards Gradebook + Peer Review

03Schema (8 tables)
Schema
  1. cls_standard_grades — student_id UUID FK, standard_id UUID FK(cur_standards), class_id UUID FK, proficiency_level TEXT NOT NULL 5-value CHECK (EXCEEDING, MEETING, APPROACHING, BELOW, NOT_ASSESSED), assessed_by UUID FK, assessed_at TIMESTAMPTZ. UNIQUE(student_id, standard_id, class_id). Standards-based grading distinct from traditional cls_grades.
  2. cls_standard_grade_evidence — standard_grade_id UUID FK, evidence_type TEXT NOT NULL 4-value CHECK (SUBMISSION, OBSERVATION, ASSESSMENT, TEACHER_NOTE), evidence_ref_id UUID (soft to cls_submissions, cls_grades, etc.), description TEXT, added_at TIMESTAMPTZ. INDEX(standard_grade_id). Links proficiency ratings to the work that demonstrates them.
  3. cls_peer_review_assignments — assignment_id UUID FK(cls_assignments) NOT NULL, review_type TEXT NOT NULL 2-value CHECK (RANDOM, TEACHER_ASSIGNED), reviews_per_student INT NOT NULL DEFAULT 2, is_anonymous BOOLEAN DEFAULT true, rubric_id UUID FK(cls_rubrics) nullable (when set: peer reviewers score using this rubric), due_date TIMESTAMPTZ. UNIQUE(assignment_id). Peer review is opt-in per assignment.
  4. cls_peer_reviews — peer_assignment_id UUID FK NOT NULL, reviewer_student_id UUID FK NOT NULL, reviewee_submission_id UUID FK(cls_submissions) NOT NULL, feedback TEXT, overall_rating TEXT 4-value CHECK (EXCELLENT, GOOD, DEVELOPING, NEEDS_WORK) nullable, status TEXT NOT NULL DEFAULT 'ASSIGNED' 3-value CHECK (ASSIGNED, SUBMITTED, REVIEWED_BY_TEACHER), submitted_at TIMESTAMPTZ. UNIQUE(peer_assignment_id, reviewer_student_id, reviewee_submission_id). When is_anonymous=true: reviewer identity hidden from reviewee.
  5. cls_student_progress_notes — class_id UUID FK, student_id UUID FK, teacher_id UUID FK, note_text TEXT NOT NULL, note_type TEXT NOT NULL 3-value CHECK (PROGRESS, CONCERN, COMMENDATION), is_shared_with_parent BOOLEAN DEFAULT false. INDEX(class_id, student_id, created_at DESC). Lighter than report cards — mid-term observations.
  6. cls_report_card_subjects — report_card_id UUID FK(cls_report_cards), subject_label TEXT NOT NULL (snapshot — may differ from sis_courses), course_id UUID nullable (soft to sis_courses), final_grade TEXT, grade_value NUMERIC(5,2), teacher_comments TEXT, effort_grade TEXT. INDEX(report_card_id).
  7. cls_formative_assessments — class_id UUID FK, created_by UUID FK, title TEXT NOT NULL, assessment_type TEXT NOT NULL 4-value CHECK (EXIT_TICKET, POLL, QUICK_CHECK, DO_NOW), questions JSONB NOT NULL, is_active BOOLEAN DEFAULT false. INDEX(class_id, is_active).
  8. cls_formative_responses — assessment_id UUID FK, student_id UUID FK, responses JSONB NOT NULL, submitted_at TIMESTAMPTZ. UNIQUE(assessment_id, student_id). Real-time classroom check-for-understanding.
Produces → 8 tables. Migration: 113_cls_standards_peer.sql.

UI

  2. Peer Review Manager (inline on assignment) — teacher enables peer review. Config: reviews per student, anonymous toggle, rubric selection. Student: review queue with submission to read + feedback form.
  3. Progress Notes (inline on student profile in classroom) — teacher writes + categorises notes. Share toggle for parent visibility.
  4. Formative Assessment /classroom/formative — teacher creates quick check. Activates live. Students respond on devices. Real-time response bar chart.

P2-7c: AI Tutoring + Lesson Video

External Service Dependencies

P2-7c requires two extracted services: AI Inference (AI Gateway per ADR-004) for tutoring conversation + learning signal extraction + lesson summary generation, and Video Processing for lesson video transcription. If these services are not yet deployed, the schema + service layer can still be built with stubbed AI/video calls — the pipeline processes manually-entered transcripts and returns placeholder summaries. Swap in the real services when deployed.

05Schema (8 tables)
Schema
  1. cls_ai_tutoring_sessions — student_id UUID FK, class_id UUID FK, subject TEXT NOT NULL, started_at TIMESTAMPTZ, ended_at TIMESTAMPTZ, status TEXT 3-value CHECK (ACTIVE, COMPLETED, ABANDONED), total_messages INT DEFAULT 0, learning_signals_extracted BOOLEAN DEFAULT false. INDEX(student_id, started_at DESC). AI must never access student PII — anonymised IDs only per ADR-004.
  2. cls_ai_tutoring_messages — session_id UUID FK NOT NULL, role TEXT NOT NULL 2-value CHECK (STUDENT, ASSISTANT), content TEXT NOT NULL, sent_at TIMESTAMPTZ NOT NULL, tokens_used INT. INDEX(session_id, sent_at). RANGE partition by created_at monthly.
  3. cls_ai_tutoring_learning_signals — session_id UUID FK NOT NULL, signal_type TEXT NOT NULL 5-value CHECK (MISCONCEPTION, STRENGTH, STRUGGLE, INTEREST, ENGAGEMENT), signal_description TEXT NOT NULL, standard_id UUID (soft to cur_standards), confidence NUMERIC(3,2), extracted_at TIMESTAMPTZ. INDEX(session_id). Visible to teacher + counsellor (with consent per ADR-004). Never visible to other students.
  4. cls_lesson_recordings — lesson_id UUID FK(cls_lessons), class_id UUID FK, recorded_by UUID FK, s3_key TEXT NOT NULL, duration_seconds INT, recorded_at TIMESTAMPTZ, processing_status TEXT NOT NULL DEFAULT 'UPLOADED' 4-value CHECK (UPLOADED, TRANSCRIBING, SUMMARISING, COMPLETE). Emits video.uploaded for transcription pipeline.
  5. cls_lesson_transcripts — recording_id UUID FK UNIQUE, transcript_text TEXT NOT NULL, word_count INT, language TEXT DEFAULT 'en', generated_at TIMESTAMPTZ. Produced by Video Processing service consuming video.uploaded.
  6. cls_lesson_summaries — recording_id UUID FK UNIQUE, summary_text TEXT NOT NULL, key_topics TEXT[], action_items TEXT[], model_version TEXT, generated_at TIMESTAMPTZ. Produced by AI Inference service. Emits lesson.summary.ready for teacher notification.
  7. cls_ai_usage_log — school_id UUID, job_type TEXT NOT NULL 4-value CHECK (GRADING, SUMMARISATION, TUTORING, STUDENT_SUMMARY), tokens_used INT, cost_usd NUMERIC(8,4), created_at TIMESTAMPTZ. RANGE partition by created_at monthly. Per-tenant AI quota enforcement via Redis counters.
  8. cls_ai_tutoring_opt_outs — student_id UUID FK, opted_out_by UUID FK NOT NULL (parent or student ≥13), opted_out_at TIMESTAMPTZ, reason TEXT. UNIQUE(student_id). When opted out: AI tutoring endpoint returns 403 for this student.
Produces → 8 tables. Migration: 114_cls_ai_tutoring_video.sql.
06Seed + Services + UI + Tests
SeedCodeUITest
Seed
  1. 2 tutoring sessions (1 COMPLETED with 8 messages + 3 learning signals, 1 ACTIVE). 1 lesson recording (COMPLETE with transcript + summary). 3 AI usage log entries. 1 opt-out (parent opted out Ethan).
Services (~16 endpoints)
  1. AITutoringService — POST /classroom/ai-tutoring/sessions (start session — checks opt-out, checks quota), POST /classroom/ai-tutoring/sessions/:id/message (student sends message → AI Gateway → response; logs tokens to cls_ai_usage_log; checks quota per message), GET /classroom/ai-tutoring/sessions (student: own; teacher: students in my classes), POST /classroom/ai-tutoring/sessions/:id/extract-signals (AI Gateway extracts learning signals from conversation history). GET /classroom/students/:id/learning-signals (teacher + counsellor: signals for a student).
  2. LessonRecordingService — POST /classroom/lessons/:id/recordings (upload video to S3 → emits video.uploaded), GET /classroom/recordings/:id (with transcript + summary inlined when available). VideoTranscriptConsumer: consumes video.transcribed → creates cls_lesson_transcripts → emits for summarisation. LessonSummaryConsumer: consumes lesson.summary.ready → creates cls_lesson_summaries.
  3. AIUsageService — GET /classroom/ai-usage (admin: per-school usage + cost), GET /classroom/ai-usage/quota (remaining daily tokens for this tenant).
  4. AIOptOutService — POST /classroom/ai-tutoring/opt-out (parent/student opts out), DELETE /classroom/ai-tutoring/opt-out/:studentId (opt back in), GET /classroom/ai-tutoring/opt-out/:studentId (check status).
UI
  1. AI Tutor /classroom/ai-tutor — student: chat interface with subject selector. Message history. Session list. Teacher: student session history with learning signals panel.
  2. Lesson Video Manager /classroom/lessons/:id/video — teacher: upload recording. Processing status indicator. Transcript viewer. AI summary card with key topics + action items.
  3. AI Usage Dashboard /classroom/ai-usage — admin: daily/monthly usage chart. Cost breakdown by job type. Quota remaining indicator.
Produces → P2-7c: 8 tables, ~16 endpoints, 2 Kafka consumers, 3 Kafka emits. Requires AI Inference + Video Processing (stubbed if not deployed).
