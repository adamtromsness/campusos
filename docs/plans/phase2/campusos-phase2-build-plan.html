Wave Structure

Sequencing Principle

Wave A (Pilot Critical) ships before the first school logs in — without these, the school can't operate safely. Wave B (Pilot Enhancement) ships in the first 90 days of pilot — these are features the school expects but can wait a few weeks for. Wave C (Operational Depth) ships during the pilot year — deepening modules based on pilot feedback. Wave D (Module Completion) completes every module in the ERD for product maturity. Each cycle within a wave can be built in any order — all Phase 1 dependencies are satisfied.

Timeline Estimate

Build Time Estimates

Based on Phase 1 velocity (~2–3 days per cycle with Claude Code), assuming a single developer with Claude Max:

Wave A (4 cycles, 53 tables): ~2 weeks. Ship before pilot day 1.

Wave B (6 cycles, 92 tables): ~3 weeks. Ship within first 90 days of pilot.

Wave C (7 cycles, 105 tables): ~3 weeks. Ship during pilot year based on feedback priority.

Wave D (13 cycles, 172 tables): ~5 weeks. Ship post-pilot for product maturity.

Total Phase 2: ~13 weeks (~3 months). Combined with Phase 1 (~6 months), the complete 840-table ERD ships in ~9 months.
