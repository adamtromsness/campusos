P2-21: Platform Advanced

CampusOS-the-company's internal tooling: CRM with customer accounts, subscriptions, onboarding tracking, health scoring, and renewal pipeline (ADR-071); internal operations with employee management, FERPA/GDPR-audited tenant access grants (4-hour maximum), and internal ticketing (ADR-072); platform pricing infrastructure; and the Community Exchange marketplace with polymorphic listings, school-to-school asset transactions with 5% platform fee, condition reports, watch lists, community profiles with reputation, ratings, and unified tsvector search (ADR-073..076). All tables in the PLATFORM schema. Pre-split into 3 sub-cycles.
May 2026 · 3 Sub-Cycles · ERD v11 · M90 + M91 + Community Exchange (26 tables) · CRM-001..006 + OPS-001..006 + MKT-001..010 · Phase 2 Cycle 21
ALL PLATFORM SCHEMA — Not Tenant

Every table in this cycle lives in the platform schema, not the tenant schema. These tables serve CampusOS-the-company (CRM, ops, pricing) and the cross-school community (marketplace, profiles, search). Platform migrations go in the platform migrations directory. No tenant schema tables are created or modified.

Sub-Cycle Structure

P2-21a — CRM: Customer & Subscriptions (9 tables)

M90 Customer Management: customer accounts linked to schools/organisations with lifecycle (PROSPECT → PILOT → ONBOARDING → ACTIVE → CHURNED), subscriptions with Stripe billing, contacts with roles and champions, interaction logging, onboarding checklists with task tracking, automated health scoring, renewal pipeline, and platform invoicing. ADR-071. Internal-only — not visible to school tenants.

P2-21b — Internal Ops + Pricing (9 tables)

M91 Internal Operations: CampusOS employee records (separate from school hr_employees), role-based internal permissions, account assignments (CSM → account mapping), FERPA/GDPR-audited tenant access grants with 4-hour maximum + mandatory justification, internal ticketing for cross-team work. Plus platform pricing infrastructure: pricing bands, price change history, support tier definitions. ADR-072. Internal-only.

P2-21c — Community Exchange (8 tables)

Cross-school marketplace with 6 polymorphic listing types (educational, portfolio, field_trip, surplus_asset, book, knowledge), school-to-school asset transactions with 5% platform fee + Stripe settlement, condition reports (seller listing + buyer receipt), watch lists with auto-notification on match, community profiles with privacy controls + reputation scoring, star ratings on all content types, and unified PostgreSQL tsvector search across all community content. ADR-073..076. Visible to all authenticated users including parents (browse + buy; cannot create listings).

P2-21a: CRM (M90)

01Schema (9 tables)
Schema
  1. crm_accounts — school_id UUID FK(schools) nullable, organisation_id UUID FK(organisations) nullable, account_name TEXT NOT NULL, pricing_band_id UUID FK, status TEXT NOT NULL DEFAULT 'PROSPECT' 6-value CHECK (PROSPECT, PILOT, ONBOARDING, ACTIVE, CHURNED, SUSPENDED), billing_email TEXT NOT NULL, billing_address_json JSONB, stripe_customer_id TEXT UNIQUE, school_champion_person_id UUID FK(iam_person), signed_date DATE, go_live_date DATE, renewal_date DATE. CHECK(school_id IS NOT NULL OR organisation_id IS NOT NULL). INDEX(status). INDEX(renewal_date) WHERE status='ACTIVE'.
  2. crm_subscriptions — account_id UUID FK NOT NULL, plan_name TEXT NOT NULL, stripe_subscription_id TEXT UNIQUE, billing_interval TEXT NOT NULL 2-value CHECK (MONTHLY, ANNUAL), mrr_cents INT NOT NULL, student_count_at_sign INT, status TEXT NOT NULL 4-value CHECK (TRIALING, ACTIVE, PAST_DUE, CANCELLED), current_period_start DATE, current_period_end DATE, cancel_at_period_end BOOLEAN DEFAULT false. INDEX(account_id, status).
  3. crm_contacts — account_id UUID FK NOT NULL, person_id UUID FK(iam_person), name TEXT NOT NULL, email TEXT NOT NULL, phone TEXT, role TEXT NOT NULL 6-value CHECK (DECISION_MAKER, CHAMPION, ADMIN_CONTACT, BILLING_CONTACT, TECHNICAL_CONTACT, OTHER), is_primary BOOLEAN DEFAULT false. INDEX(account_id).
  4. crm_interactions — account_id UUID FK NOT NULL, contact_id UUID FK, interaction_type TEXT NOT NULL 7-value CHECK (CALL, EMAIL, MEETING, DEMO, SUPPORT, NOTE, OTHER), subject TEXT NOT NULL, notes TEXT, logged_by UUID NOT NULL, interaction_at TIMESTAMPTZ NOT NULL. INDEX(account_id, interaction_at DESC).
  5. crm_onboarding_checklists — account_id UUID FK NOT NULL UNIQUE, template_version INT DEFAULT 1, started_at TIMESTAMPTZ, completed_at TIMESTAMPTZ, status TEXT NOT NULL DEFAULT 'NOT_STARTED' 3-value CHECK (NOT_STARTED, IN_PROGRESS, COMPLETED). On COMPLETED: account.status → ACTIVE if currently ONBOARDING.
  6. crm_onboarding_tasks — checklist_id UUID FK NOT NULL, task_name TEXT NOT NULL, task_category TEXT NOT NULL 5-value CHECK (TECHNICAL, DATA_MIGRATION, TRAINING, CONFIGURATION, GO_LIVE), sort_order INT NOT NULL, status TEXT NOT NULL DEFAULT 'PENDING' 3-value CHECK (PENDING, COMPLETED, SKIPPED), completed_at TIMESTAMPTZ, completed_by UUID. INDEX(checklist_id, sort_order).
  7. crm_health_scores — account_id UUID FK NOT NULL, score_date DATE NOT NULL, overall_score INT NOT NULL CHECK(0..100), adoption_score INT, engagement_score INT, support_ticket_score INT, nps_score INT, risk_level TEXT NOT NULL 3-value CHECK (HEALTHY, AT_RISK, CRITICAL). UNIQUE(account_id, score_date). HealthScoreWorker: weekly computation from usage metrics + support tickets + NPS.
  8. crm_renewal_pipeline — account_id UUID FK NOT NULL, renewal_date DATE NOT NULL, current_mrr_cents INT NOT NULL, proposed_mrr_cents INT, stage TEXT NOT NULL DEFAULT 'UPCOMING' 5-value CHECK (UPCOMING, IN_DISCUSSION, PROPOSAL_SENT, COMMITTED, CHURNING), risk_factors TEXT[], assigned_csm UUID, notes TEXT. INDEX(renewal_date, stage).
  9. crm_invoices — account_id UUID FK NOT NULL, stripe_invoice_id TEXT UNIQUE, amount_cents INT NOT NULL, currency TEXT DEFAULT 'usd', status TEXT NOT NULL 4-value CHECK (DRAFT, OPEN, PAID, VOID), invoice_date DATE NOT NULL, due_date DATE NOT NULL, paid_at TIMESTAMPTZ, pdf_url TEXT. INDEX(account_id, invoice_date DESC).
Produces → 9 PLATFORM tables. Migration: 142_platform_crm.sql.

P2-21b: Internal Ops + Pricing (M91 + Pricing)

03Schema (9 tables)
Schema
  1. ops_employees — person_id UUID FK(iam_person) NOT NULL UNIQUE, department TEXT NOT NULL 6-value CHECK (ENGINEERING, PRODUCT, SALES, CUSTOMER_SUCCESS, SUPPORT, OPERATIONS), role TEXT NOT NULL, hire_date DATE NOT NULL, is_active BOOLEAN DEFAULT true. CampusOS staff — separate from school hr_employees.
  2. ops_permissions — employee_id UUID FK NOT NULL, scope TEXT NOT NULL 5-value CHECK (CRM_READ, CRM_WRITE, TENANT_ACCESS, INTERNAL_ADMIN, SUPPORT), granted_by UUID FK NOT NULL, granted_at TIMESTAMPTZ NOT NULL. UNIQUE(employee_id, scope).
  3. ops_account_assignments — account_id UUID FK(crm_accounts) NOT NULL, employee_id UUID FK(ops_employees) NOT NULL, assignment_role TEXT NOT NULL 3-value CHECK (CSM, TAM, AE), is_primary BOOLEAN DEFAULT false. UNIQUE(account_id, employee_id). INDEX(employee_id).
  4. ops_tenant_access_grants — employee_id UUID FK NOT NULL, tenant_schema TEXT NOT NULL, justification TEXT NOT NULL CHECK(length(trim(justification)) ≥ 20), access_type TEXT NOT NULL 2-value CHECK (READ_ONLY, READ_WRITE), granted_at TIMESTAMPTZ NOT NULL, expires_at TIMESTAMPTZ NOT NULL CHECK(expires_at ≤ granted_at + INTERVAL '4 hours'), revoked_at TIMESTAMPTZ, approved_by UUID FK NOT NULL. INDEX(employee_id, expires_at) WHERE revoked_at IS NULL. ADR-072: FERPA/GDPR-audited, 4-hour maximum, mandatory justification. Emits ops.tenant_access.granted.
  5. ops_internal_tickets — title TEXT NOT NULL, description TEXT NOT NULL, category TEXT NOT NULL 5-value CHECK (BUG, FEATURE_REQUEST, DATA_FIX, INFRASTRUCTURE, OTHER), priority TEXT NOT NULL DEFAULT 'MEDIUM' 4-value CHECK (LOW, MEDIUM, HIGH, CRITICAL), status TEXT NOT NULL DEFAULT 'OPEN' 5-value CHECK (OPEN, IN_PROGRESS, BLOCKED, RESOLVED, CLOSED), created_by UUID FK NOT NULL, assigned_to UUID FK, related_account_id UUID FK(crm_accounts). INDEX(status, priority).
  6. ops_internal_ticket_comments — ticket_id UUID FK NOT NULL, author_id UUID FK NOT NULL, comment_text TEXT NOT NULL. INDEX(ticket_id, created_at).
  7. platform_pricing_bands — name TEXT NOT NULL UNIQUE, student_range_min INT NOT NULL, student_range_max INT, monthly_price_cents INT NOT NULL, annual_price_cents INT NOT NULL, is_active BOOLEAN DEFAULT true. Pricing by school size.
  8. platform_pricing_history — band_id UUID FK NOT NULL, previous_monthly_cents INT, new_monthly_cents INT NOT NULL, previous_annual_cents INT, new_annual_cents INT NOT NULL, effective_date DATE NOT NULL, changed_by UUID FK NOT NULL. INDEX(band_id, effective_date DESC). Price change audit trail.
  9. platform_support_tiers — name TEXT NOT NULL UNIQUE, response_time_hours INT NOT NULL, includes_phone BOOLEAN DEFAULT false, includes_dedicated_csm BOOLEAN DEFAULT false, monthly_addon_cents INT DEFAULT 0, is_active BOOLEAN DEFAULT true.
Produces → 9 PLATFORM tables. Migration: 143_platform_ops_pricing.sql.

P2-21c: Community Exchange

05Schema (8 tables)
Schema
  1. platform_community_profiles — person_id UUID FK(iam_person) NOT NULL UNIQUE, display_name TEXT NOT NULL, bio TEXT, school_name TEXT, role_label TEXT, avatar_s3_key TEXT, reputation_points INT DEFAULT 0, is_public BOOLEAN DEFAULT true. All user types including parents. INDEX(reputation_points DESC).
  2. platform_marketplace_listings — listing_type TEXT NOT NULL 6-value CHECK (EDUCATIONAL, PORTFOLIO, FIELD_TRIP, SURPLUS_ASSET, BOOK, KNOWLEDGE), title TEXT NOT NULL, description TEXT NOT NULL, seller_school_id UUID FK(schools) NOT NULL, seller_profile_id UUID FK NOT NULL, price_cents INT (null = free), condition TEXT 5-value CHECK (NEW, LIKE_NEW, GOOD, FAIR, POOR) nullable, category TEXT, tags TEXT[], photo_s3_keys JSONB, status TEXT NOT NULL DEFAULT 'DRAFT' 4-value CHECK (DRAFT, ACTIVE, SOLD, EXPIRED), search_keywords TSVECTOR. INDEX using GIN(search_keywords). INDEX(listing_type, status) WHERE status='ACTIVE'. Parents can browse + buy but cannot create listings.
  3. platform_asset_transactions — listing_id UUID FK NOT NULL, buyer_type TEXT NOT NULL 2-value CHECK (SCHOOL, INDIVIDUAL), buyer_school_id UUID FK(schools), buyer_person_id UUID FK(iam_person), seller_school_id UUID FK NOT NULL, quantity INT DEFAULT 1, unit_price_cents INT NOT NULL, total_price_cents INT NOT NULL, platform_fee_cents INT NOT NULL (5%), seller_receives_cents INT NOT NULL (95%), CHECK(platform_fee_cents + seller_receives_cents = total_price_cents), stripe_payment_intent_id TEXT, status TEXT NOT NULL DEFAULT 'PENDING_PAYMENT' 7-value CHECK (PENDING_PAYMENT, PAID, SHIPPING, DELIVERED, CONFIRMED, DISPUTED, REFUNDED), shipping_method TEXT 3-value CHECK (PICKUP, SCHOOL_DELIVERY, CARRIER), tracking_number TEXT. Emits mkt.transaction.completed.
  4. platform_asset_condition_reports — transaction_id UUID FK NOT NULL, reporter_type TEXT NOT NULL 2-value CHECK (SELLER_LISTING, BUYER_RECEIPT), condition TEXT NOT NULL 5-value CHECK (NEW, LIKE_NEW, GOOD, FAIR, POOR), condition_notes TEXT, photo_s3_keys JSONB, reported_by UUID FK NOT NULL, reported_at TIMESTAMPTZ NOT NULL. UNIQUE(transaction_id, reporter_type).
  5. platform_marketplace_watch_lists — school_id UUID FK NOT NULL, target_listing_type TEXT NOT NULL, search_keywords TEXT, max_price_cents INT, condition_min TEXT 5-value CHECK (NEW, LIKE_NEW, GOOD, FAIR, POOR), status TEXT NOT NULL DEFAULT 'ACTIVE' 2-value CHECK (ACTIVE, FULFILLED), created_by UUID FK NOT NULL. INDEX(target_listing_type, status). WatchListMatchWorker: on new listing → checks active watch lists → notifies matching schools.
  6. platform_community_ratings — rateable_type TEXT NOT NULL 3-value CHECK (LISTING, TRANSACTION, FORUM_POST), rateable_id UUID NOT NULL, rated_by UUID FK NOT NULL, score INT NOT NULL CHECK(1..5), review_text TEXT, helpful_votes INT DEFAULT 0. UNIQUE(rateable_type, rateable_id, rated_by). INDEX(rateable_type, rateable_id, score).
  7. platform_community_reputation_log — profile_id UUID FK NOT NULL, points_delta INT NOT NULL, reason TEXT NOT NULL 6-value CHECK (LISTING_SOLD, RATING_RECEIVED, HELPFUL_VOTE, FORUM_ANSWER_ACCEPTED, REPORT_UPHELD, ADMIN_ADJUSTMENT), reference_id UUID. INDEX(profile_id, created_at DESC). On INSERT: updates platform_community_profiles.reputation_points.
  8. platform_search_index — content_type TEXT NOT NULL 4-value CHECK (LISTING, FORUM_POST, KNOWLEDGE_ARTICLE, PROFILE), content_id UUID NOT NULL, title TEXT NOT NULL, body_preview TEXT, search_vector TSVECTOR NOT NULL, school_id UUID, author_profile_id UUID, content_date TIMESTAMPTZ. UNIQUE(content_type, content_id). INDEX using GIN(search_vector). Materialised by SearchIndexWorker on content create/update events. ADR-076.
Produces → 8 PLATFORM tables. Migration: 144_platform_community_exchange.sql. Total P2-21 tables: 26.
