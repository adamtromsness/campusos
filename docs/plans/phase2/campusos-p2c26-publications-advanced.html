Plan Overview

Phase 2 Cycle 26 builds the deferred tables from Cycle 25’s M25 Publications module — 4 new tables. Cycle 25 built the core publishing surface (series, editions, publications, sections, collaborators, distribution lists, recipients, subscriptions, media). This cycle adds the editorial workflow depth: immutable version history so editors can review or revert to any prior state, a template library so schools don’t start newsletters from scratch, scheduled publishing so the Friday newsletter queues on Wednesday and auto-publishes at 3pm Friday, and engagement analytics so the communications team knows which publications actually get read.

IMMUTABLE — pub_publication_versions

pub_publication_versions is IMMUTABLE — no UPDATE, no DELETE at the service layer. Each version is a complete JSONB snapshot of the publication’s content at that point in time. Versions are created automatically on every status transition (DRAFT → IN_REVIEW → APPROVED → PUBLISHED) and on explicit “Save Checkpoint” by the editor. The version trail is the publication’s audit history.

Vertical Slice Deliverable

Admin creates template “Monthly Newsletter” with 5 pre-populated sections → editor creates new publication from template → sections auto-populated → editor writes content → saves checkpoint → v1 created (IMMUTABLE) → submits for review → v2 auto-created → reviewer approves → v3 → editor schedules publish for Friday 3pm EST → ScheduledPublishWorker fires → PUBLISHED → v4 (final) → distribution triggered → after 48 hours: 450 views, 312 opens, 89 clicks → editor views version history → can preview any version → reverts to v2 → creates new v5 based on v2’s snapshot (append-only).

What’s In / What’s Deferred

In scope (4 tables): pub_publication_versions, pub_templates, pub_scheduled_publications, pub_publication_analytics. Function PUB-001 extended.

Deferred: AI-generated content suggestions. A/B testing for subject lines. Rich template designer with drag-and-drop. Multi-language publication variants. PDF export. Publication archive full-text search. Collaborative real-time editing. RSS feed generation.

Step-by-Step Build Plan

01Schema (4 tables)
Schema
  1. pub_publication_versions — IMMUTABLE. publication_id UUID FK NOT NULL, version_number INT NOT NULL, snapshot_content JSONB NOT NULL, created_by UUID FK NOT NULL, version_note TEXT, trigger TEXT NOT NULL 3-value CHECK (STATUS_CHANGE, MANUAL_CHECKPOINT, REVERT). NO UPDATE, NO DELETE. UNIQUE(publication_id, version_number). INDEX(publication_id, version_number DESC).
  2. pub_templates — school_id UUID nullable (null = platform-seeded), name TEXT NOT NULL, publication_type TEXT NOT NULL, description TEXT, template_content JSONB NOT NULL, is_system BOOLEAN DEFAULT false, created_by UUID FK. UNIQUE(COALESCE(school_id, '00000000-0000-0000-0000-000000000000'), name).
  3. pub_scheduled_publications — publication_id UUID FK NOT NULL UNIQUE, scheduled_at TIMESTAMPTZ NOT NULL, timezone TEXT NOT NULL DEFAULT 'America/Chicago', status TEXT NOT NULL DEFAULT 'SCHEDULED' 3-value CHECK (SCHEDULED, PUBLISHED, CANCELLED), scheduled_by UUID FK NOT NULL, published_at TIMESTAMPTZ. INDEX(status, scheduled_at) WHERE status='SCHEDULED'.
  4. pub_publication_analytics — publication_id UUID FK NOT NULL UNIQUE, total_recipients INT DEFAULT 0, total_views INT DEFAULT 0, unique_views INT DEFAULT 0, total_opens INT DEFAULT 0, total_link_clicks INT DEFAULT 0, avg_read_time_seconds INT, last_updated_at TIMESTAMPTZ.
Produces → 4 tables. Migration: 155_pub_versions_templates.sql.
02Seed Data
Seed
  1. 5 versions for an existing publication (v1 STATUS_CHANGE, v2 MANUAL_CHECKPOINT, v3 STATUS_CHANGE, v4 REVERT, v5 STATUS_CHANGE). 3 templates (2 platform is_system=true, 1 school-custom). 1 scheduled publication (SCHEDULED, Friday 3pm). 2 analytics rows.
  2. Permissions: PUB-001 extended: templates (admin create; staff use), versions (editor + admin view), scheduling (editor + admin), analytics (editor + admin).
Produces → Publication advanced demo data.
03Version History + Template NestJS Module
Code
  1. VersionService — GET /publications/:id/versions (list without snapshot_content), GET /publications/versions/:versionId (full snapshot), POST /publications/:id/checkpoint (manual save), POST /publications/:id/revert/:versionNumber (creates NEW version from specified snapshot). Auto-hook on every status transition.
  2. TemplateService — GET /publications/templates, POST /publications/templates (admin), PATCH /publications/templates/:id (is_system=true rejects), POST /publications/from-template/:templateId (create + auto-populate sections). Platform seeder: 3 system templates.
Produces → 2 services, ~10 endpoints.
04Scheduled Publishing + Analytics NestJS Module
Code
  1. ScheduledPublishService — POST /publications/:id/schedule, DELETE /publications/:id/schedule, GET /publications/scheduled. ScheduledPublishWorker: every minute, publishes due items, emits pub.publication.published.
  2. PublicationAnalyticsService — GET /publications/:id/analytics, GET /publications/analytics/summary. AnalyticsWorker: atomic INCREMENT on delivery/open/click events.
Produces → 2 services + 2 workers, ~8 endpoints, 1 Kafka emit. Total: ~18 endpoints.
05Publications Advanced UI
UI
  1. Version History Panel — timeline sidebar with trigger badges. Preview + revert buttons. Diff view.
  2. Template Library /publications/templates — grid with previews. “Use Template” button.
  3. Schedule Publish — date/time picker with timezone. Countdown indicator.
  4. Analytics Dashboard /publications/analytics — per-publication funnel + ranking table.
Produces → Version history, template library, scheduled publish, analytics.
06Vertical Slice Integration Test
Test
  1. Version IMMUTABLE: Create + transition. Verify auto-versions. Attempt UPDATE/DELETE → rejected. Revert creates NEW version (append-only).
  2. Templates: Create from template. Verify sections auto-populated. is_system=true edit → 403.
  3. Scheduled publishing: Schedule for 1 min. Worker fires. Verify PUBLISHED + distribution + final version + Kafka emit. Cancel → CANCELLED.
  4. Analytics: Simulate events. Verify atomic increments. Concurrent events don’t lose counts.
  5. Visibility: Editor sees versions + analytics for own. Admin sees all. Students see published only.
Produces → Verified: version history (IMMUTABLE) → templates → scheduled publishing → analytics.
07Platform Template Seeder
Seed
  1. Idempotent upsert of 3 system templates (Monthly Newsletter, Weekly Bulletin, Annual Report) with school_id=NULL + is_system=true.
Produces → Idempotent platform template seeder.
