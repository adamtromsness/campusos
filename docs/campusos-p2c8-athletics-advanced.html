P2-8: Athletics Advanced

Equipment inventory with student checkout tracking and safety compliance certification, athletic conferences with membership and cross-conference scheduling, game streaming with highlight clip extraction for student portfolios, the officials marketplace with platform-level portable profiles and bidirectional ratings (ADR-063), advanced per-sport statistics with configurable categories and stat leaders, and student-athlete recruiting profiles. Pre-split into 2 sub-cycles.
May 2026 · 2 Sub-Cycles · ERD v11 · M66 Athletics .1 (18 tables) · ATH-001..004 · Phase 2 Cycle 8

Sub-Cycle Structure

18 tables split into 2 independently shippable sub-cycles. P2-8a covers the physical operations (equipment + conferences + team media). P2-8b covers the digital layer (streaming + officials marketplace + advanced stats + recruiting). Peer review happens after both are complete.

P2-8a — Equipment + Conferences + Media (9 tables)

Equipment inventory with student checkouts + safety compliance + damage tracking, athletic conferences with memberships + cross-conference scheduling, team photos + media asset library. No external service dependencies.

P2-8b — Streaming + Officials + Stats + Recruiting (9 tables)

Game streaming with access control + highlight clip extraction for portfolios (ADR-068), officials marketplace with platform-level profiles + bidirectional ratings (ADR-063), configurable advanced statistics + stat leaders, student-athlete recruiting profiles. Streaming requires Video Processing extracted service (stub if not deployed).

P2-8a: Equipment + Conferences + Media

01Schema (9 tables)
Schema
  1. ath_equipment — school_id UUID, programme_id UUID FK(ath_programmes), item_type TEXT NOT NULL 6-value CHECK (UNIFORM, PROTECTIVE_GEAR, TRAINING_EQUIPMENT, GAME_EQUIPMENT, MEDICAL_EQUIPMENT, OTHER), item_name TEXT NOT NULL, quantity INT DEFAULT 0, condition TEXT NOT NULL 5-value CHECK (EXCELLENT, GOOD, FAIR, POOR, RETIRED), purchase_date DATE, unit_cost NUMERIC(8,2). INDEX(school_id, programme_id).
  2. ath_equipment_checkouts — equipment_id UUID FK NOT NULL, assigned_to_person_id UUID FK(iam_person) NOT NULL, item_identifier TEXT (jersey number, barcode, serial), checked_out_at DATE NOT NULL, expected_return_date DATE, returned_at DATE, condition_at_return TEXT 3-value CHECK (GOOD, DAMAGED, LOST) nullable, damage_notes TEXT, replacement_charge NUMERIC(8,2). INDEX(assigned_to_person_id, returned_at) WHERE returned_at IS NULL.
  3. ath_safety_equipment — roster_member_id UUID FK(ath_roster_members) NOT NULL, equipment_type TEXT NOT NULL 6-value CHECK (HELMET, PADS, MOUTHGUARD, SHIN_GUARDS, GOGGLES, OTHER), issued BOOLEAN DEFAULT false, meets_safety_standard BOOLEAN DEFAULT true, certification_date DATE, certification_expiry DATE, recall_status BOOLEAN DEFAULT false. UNIQUE(roster_member_id, equipment_type). Safety compliance must be verified before game participation.
  4. ath_conferences — name TEXT NOT NULL, sport TEXT NOT NULL, region TEXT, governing_body TEXT, is_active BOOLEAN DEFAULT true. UNIQUE(name, sport). Platform-level (no school_id) — conferences span schools.
  5. ath_conference_memberships — conference_id UUID FK NOT NULL, school_id UUID NOT NULL, programme_id UUID FK(ath_programmes) NOT NULL, joined_date DATE NOT NULL, level TEXT (division within conference), is_active BOOLEAN DEFAULT true. UNIQUE(conference_id, school_id, programme_id).
  6. ath_conference_schedules — conference_id UUID FK NOT NULL, season_id UUID FK(ath_seasons), home_school_id UUID NOT NULL, away_school_id UUID NOT NULL, scheduled_date DATE NOT NULL, scheduled_time TIME, linked_game_id UUID FK(ath_games) nullable (populated when the game is created). INDEX(conference_id, scheduled_date).
  7. ath_team_photos — roster_id UUID FK(ath_rosters) NOT NULL, photo_type TEXT NOT NULL 3-value CHECK (TEAM_PHOTO, ACTION_SHOT, INDIVIDUAL), s3_key TEXT NOT NULL, caption TEXT, uploaded_by UUID FK, uploaded_at TIMESTAMPTZ. INDEX(roster_id).
  8. ath_media_assets — school_id UUID, programme_id UUID FK(ath_programmes), asset_type TEXT NOT NULL 4-value CHECK (PHOTO, VIDEO, DOCUMENT, LOGO), s3_key TEXT NOT NULL, title TEXT, season_id UUID FK, uploaded_by UUID FK, uploaded_at TIMESTAMPTZ. INDEX(school_id, programme_id, asset_type).
  9. ath_equipment_maintenance — equipment_id UUID FK NOT NULL, maintenance_type TEXT NOT NULL 4-value CHECK (CLEANING, REPAIR, INSPECTION, RECONDITIONING), performed_at DATE NOT NULL, performed_by TEXT, cost NUMERIC(8,2), notes TEXT, next_maintenance_date DATE. INDEX(equipment_id, performed_at DESC).
Produces → 9 tables. Migration: 115_ath_equipment_conferences.sql.
02Seed + Services + UI + Tests
SeedCodeUITest
Seed
  1. 10 equipment items across 2 programmes. 5 checkouts (3 active, 1 returned GOOD, 1 returned DAMAGED with replacement charge). 4 safety equipment rows (1 certification expired). 1 conference ("Kansas 4A") with 3 memberships + 4 scheduled conference games. 3 team photos. 5 media assets. 2 maintenance records.
Services (~20 endpoints)
  1. EquipmentService — CRUD for equipment inventory. POST /athletics/equipment/:id/checkout (assign to student), POST /athletics/equipment-checkouts/:id/return (record return + condition; if DAMAGED/LOST → optional replacement_charge linked to pay_invoices via Kafka emit). GET /athletics/equipment/overdue (past expected_return_date). POST /athletics/equipment/:id/maintenance.
  2. SafetyEquipmentService — GET /athletics/rosters/:id/safety (compliance checklist per roster member), POST /athletics/safety-equipment, PATCH /athletics/safety-equipment/:id. GET /athletics/safety-equipment/expired (certifications past expiry).
  3. ConferenceService — GET /athletics/conferences, POST /athletics/conferences, POST /athletics/conferences/:id/memberships, GET /athletics/conferences/:id/schedule, POST /athletics/conferences/:id/schedule (generate conference schedule).
  4. TeamMediaService — CRUD for team photos + media assets. GET /athletics/rosters/:id/photos, GET /athletics/programmes/:id/media.
UI
  1. Equipment Manager /athletics/equipment — inventory table with condition pills. Checkout form (student selector + item identifier). Return form (condition + damage notes). Overdue checkouts highlighted. Maintenance log.
  2. Safety Compliance /athletics/safety — per-roster checklist: each member × each required equipment type. Green=issued+certified, amber=expiring, rose=expired/missing.
  3. Conference Manager /athletics/conferences — conference list. Per-conference: member schools, season schedule grid. Schedule generation.
  4. Media Gallery /athletics/media — team photos + media assets by programme + season. Upload + tag.
Produces → P2-8a: 9 tables, ~20 endpoints. Independently shippable.

P2-8b: Streaming + Officials + Stats + Recruiting

03Schema (9 tables)
Schema
  1. ath_game_streams — game_id UUID FK(ath_games) NOT NULL UNIQUE, stream_url TEXT, stream_status TEXT NOT NULL DEFAULT 'SCHEDULED' 4-value CHECK (SCHEDULED, LIVE, ENDED, FAILED), access_level TEXT NOT NULL DEFAULT 'SCHOOL_ONLY' 4-value CHECK (PUBLIC, SCHOOL_ONLY, BOTH_SCHOOLS, COACHES_ONLY), recording_s3_key TEXT, recording_duration_seconds INT, configured_by UUID FK NOT NULL. ADR-068: athletic events are public performances — photo privacy flags do not apply.
  2. ath_highlight_clips — stream_id UUID FK(ath_game_streams) NOT NULL, student_id UUID FK NOT NULL, start_time_seconds INT NOT NULL, end_time_seconds INT NOT NULL, title TEXT, s3_key TEXT NOT NULL, added_to_portfolio BOOLEAN DEFAULT false, portfolio_item_id UUID (soft to pfl_portfolio_items), consent_status TEXT DEFAULT 'PENDING' 3-value CHECK (PENDING, CONSENTED, DECLINED). INDEX(student_id). Links to Cycle 24 portfolios.
  3. ath_game_recordings — game_id UUID FK(ath_games) NOT NULL, recording_type TEXT NOT NULL 3-value CHECK (FULL_GAME, HIGHLIGHT_REEL, COACHES_FILM), s3_key TEXT NOT NULL, duration_seconds INT, uploaded_by UUID FK, uploaded_at TIMESTAMPTZ. INDEX(game_id).
  4. platform_official_profiles — PLATFORM SCHEMA (per ADR-063). person_id UUID FK(iam_person) NOT NULL UNIQUE, sports TEXT[] NOT NULL, certification_level TEXT, certification_body TEXT, certification_expiry DATE, years_experience INT, max_travel_miles INT, base_fee NUMERIC(8,2), is_available BOOLEAN DEFAULT true. Portable across schools via platform entity cache (ADR-020).
  5. platform_official_availability — PLATFORM SCHEMA. official_profile_id UUID FK NOT NULL, available_date DATE NOT NULL, start_time TIME, end_time TIME, is_available BOOLEAN DEFAULT true. UNIQUE(official_profile_id, available_date, start_time). Officials set their availability; schools match against it.
  6. ath_official_assignments — game_id UUID FK(ath_games) NOT NULL, official_profile_id UUID (soft to platform_official_profiles), role TEXT NOT NULL 7-value CHECK (HEAD_REFEREE, ASSISTANT_REFEREE, UMPIRE, LINE_JUDGE, SCORER, TIMER, OTHER), fee NUMERIC(8,2) NOT NULL, status TEXT NOT NULL DEFAULT 'POSTED' 6-value CHECK (POSTED, ACCEPTED, CONFIRMED, COMPLETED, CANCELLED, NO_SHOW), payment_status TEXT DEFAULT 'PENDING' 3-value CHECK (PENDING, PROCESSED, PAID). Emits ath.official.assignment.completed.
  7. ath_official_ratings — assignment_id UUID FK NOT NULL, rater_type TEXT NOT NULL 2-value CHECK (SCHOOL_RATES_OFFICIAL, OFFICIAL_RATES_SCHOOL), professionalism INT CHECK(1-5), knowledge INT CHECK(1-5), communication INT CHECK(1-5), punctuality INT CHECK(1-5), overall INT CHECK(1-5), comments TEXT, rated_at TIMESTAMPTZ. UNIQUE(assignment_id, rater_type). Bidirectional: school rates official AND official rates school.
  8. ath_recruiting_profiles — student_id UUID FK NOT NULL UNIQUE, sport TEXT NOT NULL, graduation_year INT NOT NULL, position TEXT, height_inches INT, weight_lbs INT, gpa NUMERIC(4,3) (snapshot from rpt_student_academic_summary), highlight_reel_s3_key TEXT, is_published BOOLEAN DEFAULT false, coach_recommendation TEXT. Student-owned — student controls publication.
  9. ath_recruiting_interests — recruiting_profile_id UUID FK NOT NULL, college_name TEXT NOT NULL, contact_name TEXT, contact_email TEXT, interest_level TEXT NOT NULL 4-value CHECK (EXPLORING, INTERESTED, APPLIED, COMMITTED), notes TEXT. INDEX(recruiting_profile_id).
Produces → 9 tables (7 tenant + 2 platform). Migration: 116_ath_streaming_officials.sql (tenant) + 117_platform_officials.sql (platform).
04Seed + Services + UI + Tests
SeedCodeUITest
Seed
  1. 2 game streams (1 ENDED with recording, 1 SCHEDULED). 3 highlight clips (1 added to portfolio, 1 PENDING consent). 2 game recordings. 3 official profiles (platform) with availability. 4 official assignments (POSTED, ACCEPTED, COMPLETED, NO_SHOW). 2 official ratings (bidirectional). 2 recruiting profiles (1 published). 3 recruiting interests.
Services (~22 endpoints)
  1. GameStreamService — POST /athletics/games/:id/stream (configure stream with access level), PATCH /athletics/streams/:id (status: SCHEDULED → LIVE → ENDED), GET /athletics/streams/live (currently live streams). POST /athletics/streams/:id/clips (extract highlight clip with timestamps), POST /athletics/highlight-clips/:id/add-to-portfolio (creates pfl_portfolio_items entry via Kafka).
  2. OfficialService — GET /athletics/officials (search available officials by sport + date + location), POST /athletics/officials/profile (official creates/updates profile), POST /athletics/officials/availability (set availability). POST /athletics/games/:id/officials (assign official to game), PATCH /athletics/official-assignments/:id (accept/confirm/complete/cancel). POST /athletics/official-assignments/:id/rate (bidirectional rating). GET /athletics/officials/:id/ratings (average ratings).
  3. RecruitingService — GET /athletics/recruiting/:studentId, POST /athletics/recruiting (student creates profile), PATCH /athletics/recruiting/:id, POST /athletics/recruiting/:id/interests. Student-owned: only the student (or coach with permission) can edit.
UI
  1. Streaming Manager /athletics/streaming — configure stream per game. Live indicator. Recording playback. Highlight clip extractor (drag timeline to select clip range).
  2. Officials Marketplace /athletics/officials — AD: search + assign officials. Official: profile + availability calendar + assignment queue. Bidirectional rating after game. Fee tracking.
  3. Recruiting Profile /athletics/recruiting — student: build profile with stats + highlight reel + college interests. Coach: recommendation letter. Publish toggle.
