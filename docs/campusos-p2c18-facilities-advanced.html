P2-18: Facilities Advanced

Cleaning routes with ordered stop sequences and per-stop task completion tracking, custodial zone inspections with supervisor spot checks, supply audit trail with formal stocktakes and discrepancy adjustment, work order attachments (before/after photos) and parts consumption tracking, fire drill compliance logging, facilities asset lifecycle from installation through maintenance to disposal, energy meter readings with consumption trending, and space utilisation analytics. Sub-Cycle Structure

P2-18a — Cleaning Routes + Supply Audit + Work Order Depth (11 tables)

Cleaning route definitions with ordered stops and task lists, custodian route assignments (one-off + recurring), route completion tracking with per-stop status and photographic evidence, issue detection → auto-ticket, supervisor zone inspections (PASS/NEEDS_IMPROVEMENT/FAIL), supply stocktakes with expected vs actual count and discrepancy adjustments, supply transaction audit trail, work order attachments (before/after photos, quotes, invoices), work order parts consumption with cost tracking.

P2-18b — Fire Drills + Assets + Energy + Space Utilisation (10 tables)

Fire drill compliance logging with evacuation time tracking and building-level compliance alerting, facilities asset categories with depreciation configuration, individual asset lifecycle from installation through maintenance to decommission/disposal, asset maintenance records with cost tracking, asset disposals with value recovery, utility meters with type configuration, energy readings per meter with consumption computation, space utilisation records (occupancy counting), and space utilisation analytics.

P2-18a: Cleaning + Supply + Work Order Depth

01Schema (11 tables)
Schema
  1. fac_cleaning_routes — school_id UUID NOT NULL, name TEXT NOT NULL, shift TEXT NOT NULL 4-value CHECK (MORNING, AFTERNOON, EVENING, OVERNIGHT), zone_id UUID FK(fac_zones) nullable, estimated_duration_minutes INT, is_active BOOLEAN DEFAULT true. UNIQUE(school_id, name).
  2. fac_cleaning_route_stops — route_id UUID FK NOT NULL, space_id UUID FK(fac_spaces) NOT NULL, stop_order INT NOT NULL, estimated_minutes INT, cleaning_tasks TEXT[] NOT NULL DEFAULT '{}'. UNIQUE(route_id, stop_order). UNIQUE(route_id, space_id).
  3. fac_cleaning_route_assignments — route_id UUID FK NOT NULL, employee_id UUID (soft to hr_employees), assignment_date DATE, is_recurring BOOLEAN DEFAULT false, recurrence_days INT[], effective_from DATE, effective_to DATE, assigned_by UUID FK NOT NULL. UNIQUE(route_id, assignment_date) WHERE is_recurring=false AND assignment_date IS NOT NULL.
  4. fac_cleaning_route_completions — route_id UUID FK NOT NULL, assignment_id UUID FK NOT NULL, employee_id UUID NOT NULL, completion_date DATE NOT NULL, started_at TIMESTAMPTZ, completed_at TIMESTAMPTZ, overall_status TEXT NOT NULL DEFAULT 'NOT_STARTED' 4-value CHECK (NOT_STARTED, IN_PROGRESS, COMPLETED, PARTIAL). UNIQUE(route_id, employee_id, completion_date).
  5. fac_cleaning_route_stop_completions — completion_id UUID FK NOT NULL, stop_id UUID FK NOT NULL, status TEXT NOT NULL DEFAULT 'PENDING' 3-value CHECK (PENDING, COMPLETED, SKIPPED), completed_at TIMESTAMPTZ, skip_reason TEXT, tasks_completed TEXT[], photo_s3_keys TEXT[], issues_noted TEXT. UNIQUE(completion_id, stop_id). On issues_noted IS NOT NULL: emit fac.route_stop.issue_noted → Task Worker creates tkt_ticket.
  6. fac_zone_inspections — zone_id UUID FK(fac_zones) NOT NULL, inspector_id UUID NOT NULL, inspection_date DATE NOT NULL, overall_rating TEXT NOT NULL 3-value CHECK (PASS, NEEDS_IMPROVEMENT, FAIL), notes TEXT, follow_up_required BOOLEAN DEFAULT false, follow_up_work_order_id UUID (soft to fac_work_orders). INDEX(zone_id, inspection_date DESC). On FAIL: auto-creates follow-up work order.
  7. fac_supply_transactions — building_id UUID FK NOT NULL, inventory_id UUID FK(fac_supply_inventory) NOT NULL, transaction_type TEXT NOT NULL 5-value CHECK (RECEIPT, USAGE, ADJUSTMENT, TRANSFER, WRITE_OFF), quantity_delta NUMERIC(8,2) NOT NULL, performed_by UUID FK NOT NULL, transaction_at TIMESTAMPTZ NOT NULL, reference_id UUID, notes TEXT. INDEX(inventory_id, transaction_at DESC). Audit trail for all supply movements.
  8. fac_supply_stocktakes — school_id UUID NOT NULL, building_id UUID FK NOT NULL, conducted_by UUID FK NOT NULL, stocktake_date DATE NOT NULL, status TEXT NOT NULL DEFAULT 'IN_PROGRESS' 2-value CHECK (IN_PROGRESS, COMPLETED), completed_at TIMESTAMPTZ. INDEX(building_id, stocktake_date DESC).
  9. fac_supply_stocktake_items — stocktake_id UUID FK NOT NULL, inventory_id UUID FK(fac_supply_inventory) NOT NULL, expected_quantity NUMERIC(8,2) NOT NULL, actual_quantity NUMERIC(8,2) NOT NULL, discrepancy_notes TEXT. UNIQUE(stocktake_id, inventory_id). On COMPLETED: creates ADJUSTMENT transactions for discrepancies.
  10. fac_work_order_attachments — work_order_id UUID FK NOT NULL, s3_key TEXT NOT NULL, filename TEXT NOT NULL, attachment_type TEXT NOT NULL DEFAULT 'OTHER' 6-value CHECK (PHOTO_BEFORE, PHOTO_AFTER, QUOTE, INVOICE, REPORT, OTHER), uploaded_by UUID FK NOT NULL, uploaded_at TIMESTAMPTZ NOT NULL. INDEX(work_order_id, attachment_type).
  11. fac_work_order_parts — work_order_id UUID FK NOT NULL, part_name TEXT NOT NULL, quantity NUMERIC(8,2) NOT NULL, unit TEXT, unit_cost NUMERIC(8,2), total_cost NUMERIC(10,2), supplier TEXT. INDEX(work_order_id).
Produces → 11 tables. Migration: 136_fac_cleaning_supply.sql.
02Seed + Services + UI + Tests (P2-18a)
SeedCodeUITest
Seed
  1. 2 cleaning routes ("North Wing Evening" 6 stops, "Gymnasium AM" 3 stops). 2 assignments (1 recurring weekdays, 1 one-off). 2 completions (1 COMPLETED, 1 PARTIAL with 1 skipped stop). 8 stop completions (6 COMPLETED, 1 SKIPPED with reason, 1 with issue_noted). 2 zone inspections (1 PASS, 1 FAIL with follow-up work order). 10 supply transactions. 1 stocktake COMPLETED with 8 items (2 with discrepancies → adjustments created). 3 work order attachments (PHOTO_BEFORE, PHOTO_AFTER, INVOICE). 4 work order parts.
Services (~24 endpoints)
  1. CleaningRouteService — CRUD for routes + stops (drag-reorder). POST /facilities/cleaning-routes/:id/assignments (assign custodian). POST /facilities/cleaning-completions (start route run). PATCH /facilities/cleaning-completions/:id/stops/:stopId (complete/skip stop with tasks + photos). On stop issue_noted: emit fac.route_stop.issue_noted. GET /facilities/cleaning-completions (daily dashboard).
  2. ZoneInspectionService — POST /facilities/zone-inspections (supervisor spot check), GET /facilities/zone-inspections. On FAIL: auto-create follow-up work order.
  3. SupplyAuditService — POST /facilities/supply-transactions (record receipt/usage/write-off), GET /facilities/supply-transactions/:inventoryId. POST /facilities/stocktakes, POST /facilities/stocktakes/:id/items (record counts), POST /facilities/stocktakes/:id/complete (creates ADJUSTMENT transactions for discrepancies).
  4. WorkOrderDepthService — POST /facilities/work-orders/:id/attachments, POST /facilities/work-orders/:id/parts, GET /facilities/work-orders/:id/cost-summary (parts + labour total).
UI
  1. Cleaning Routes Manager /facilities/cleaning — route builder with drag-reorder stops. Assignment calendar. Custodian: mobile-friendly route completion flow (swipe through stops, mark tasks, take photos). Dashboard: completion rates, skipped stops, issues raised.
  2. Zone Inspections /facilities/inspections — supervisor: spot check form with rating + notes. History per zone. FAIL auto-creates work order.
  3. Supply Stocktake /facilities/stocktakes — start stocktake by building. Per-item: expected vs actual. Discrepancy report. Complete → adjustments applied.
Produces → P2-18a: 11 tables, ~24 endpoints, 1 Kafka emit. Independently shippable.

P2-18b: Fire Drills + Assets + Energy + Utilisation

03Schema (10 tables)
Schema
  1. fac_fire_drills — school_id UUID NOT NULL, building_id UUID FK NOT NULL, drill_date DATE NOT NULL, drill_time TIME NOT NULL, duration_seconds INT NOT NULL, total_occupants INT NOT NULL, evacuation_time_seconds INT NOT NULL, issues_noted TEXT, met_target BOOLEAN, target_evacuation_seconds INT, conducted_by UUID FK NOT NULL. INDEX(building_id, drill_date DESC). Alert: if no drill for a building in 90 days.
  2. fac_asset_categories — school_id UUID, name TEXT NOT NULL, depreciation_years INT, maintenance_interval_months INT. UNIQUE(school_id, name). Categories: HVAC, Plumbing, Electrical, Elevator, Fire Safety, etc.
  3. fac_assets — school_id UUID NOT NULL, category_id UUID FK NOT NULL, building_id UUID FK NOT NULL, space_id UUID FK, name TEXT NOT NULL, make TEXT, model TEXT, serial_number TEXT, install_date DATE, warranty_expiry DATE, expected_lifespan_years INT, replacement_cost_estimate NUMERIC(10,2), replacement_priority TEXT 4-value CHECK (LOW, MEDIUM, HIGH, CRITICAL), status TEXT NOT NULL DEFAULT 'ACTIVE' 3-value CHECK (ACTIVE, UNDER_MAINTENANCE, DECOMMISSIONED). UNIQUE(school_id, serial_number) WHERE serial_number IS NOT NULL. INDEX(school_id, status).
  4. fac_asset_maintenance_records — asset_id UUID FK NOT NULL, maintenance_type TEXT NOT NULL 4-value CHECK (SCHEDULED, CORRECTIVE, EMERGENCY, INSPECTION), performed_date DATE NOT NULL, performed_by TEXT NOT NULL, cost NUMERIC(10,2), description TEXT NOT NULL, next_maintenance_date DATE. INDEX(asset_id, performed_date DESC). Alert: overdue maintenance when next_maintenance_date < today.
  5. fac_asset_disposals — school_id UUID NOT NULL, asset_id UUID FK NOT NULL UNIQUE, disposal_method TEXT NOT NULL 6-value CHECK (AUCTION, DONATION, SKIP, TRADE_IN, SCRAP, TRANSFER), disposal_date DATE NOT NULL, value_recovered NUMERIC(10,2), recipient_name TEXT, disposed_by UUID FK NOT NULL, authorised_by UUID FK NOT NULL, notes TEXT. On INSERT: fac_assets.status must be DECOMMISSIONED.
  6. fac_utility_meters — school_id UUID NOT NULL, building_id UUID FK NOT NULL, meter_name TEXT NOT NULL, utility_type TEXT NOT NULL 5-value CHECK (ELECTRICITY, GAS, WATER, HEATING_OIL, SOLAR), meter_reference TEXT, unit TEXT NOT NULL (kWh, therms, gallons, litres), is_active BOOLEAN DEFAULT true. UNIQUE(school_id, meter_name).
  7. fac_energy_readings — meter_id UUID FK NOT NULL, reading_date DATE NOT NULL, reading_value NUMERIC(12,2) NOT NULL, recorded_by UUID FK NOT NULL, consumption NUMERIC(10,2) (auto-computed: current reading minus previous reading for this meter), cost_estimate NUMERIC(10,2). UNIQUE(meter_id, reading_date). INDEX(meter_id, reading_date DESC).
  8. fac_energy_targets — school_id UUID NOT NULL, utility_type TEXT NOT NULL, target_period TEXT NOT NULL 2-value CHECK (MONTHLY, ANNUAL), target_value NUMERIC(12,2) NOT NULL, academic_year TEXT. UNIQUE(school_id, utility_type, target_period, academic_year). Baseline targets for consumption trending.
  9. fac_space_utilization_records — space_id UUID FK(fac_spaces) NOT NULL, record_date DATE NOT NULL, period_id UUID FK(sch_periods), occupancy_count INT, capacity INT, utilisation_rate NUMERIC(5,4) (occupancy/capacity). UNIQUE(space_id, record_date, period_id). Populated from attendance data or manual counts.
  10. fac_sustainability_initiatives — school_id UUID NOT NULL, name TEXT NOT NULL, description TEXT, category TEXT NOT NULL 5-value CHECK (ENERGY, WATER, WASTE, TRANSPORT, BIODIVERSITY), start_date DATE NOT NULL, target_reduction_percent NUMERIC(5,2), status TEXT NOT NULL DEFAULT 'ACTIVE' 3-value CHECK (ACTIVE, COMPLETED, CANCELLED), outcome_notes TEXT. UNIQUE(school_id, name).
Produces → 10 tables. Migration: 137_fac_assets_energy.sql. Total P2-18 tables: 21.
04Seed + Services + UI + Tests (P2-18b)
SeedCodeUITest
Seed
  1. 2 fire drills (1 met target, 1 did not — issues noted). 3 asset categories (HVAC, Electrical, Elevator). 8 assets (5 ACTIVE, 2 UNDER_MAINTENANCE, 1 DECOMMISSIONED). 5 maintenance records (1 overdue next maintenance). 1 disposal (DECOMMISSIONED elevator → SCRAP). 3 utility meters (electricity, gas, water). 12 energy readings across 3 meters with auto-computed consumption. 2 energy targets. 10 space utilisation records. 2 sustainability initiatives.
Services (~22 endpoints)
  1. FireDrillService — POST /facilities/fire-drills, GET /facilities/fire-drills, GET /facilities/fire-drills/compliance (buildings with no drill in 90 days). Emits fac.fire_drill.overdue.
  2. AssetService — CRUD for categories + assets. POST /facilities/assets/:id/maintenance (record maintenance + set next_maintenance_date). PATCH /facilities/assets/:id/decommission (ACTIVE → DECOMMISSIONED). POST /facilities/assets/:id/dispose (creates disposal record; validates status=DECOMMISSIONED). GET /facilities/assets/maintenance-overdue. GET /facilities/assets/replacement-planning (approaching end of lifespan, sorted by priority).
  3. EnergyService — CRUD for meters + targets. POST /facilities/energy-readings (record reading; auto-compute consumption from previous reading). GET /facilities/energy/:meterId/trend (consumption chart). GET /facilities/energy/summary (school-wide: actual vs target by utility type).
  4. SpaceUtilisationService — POST /facilities/space-utilisation (record occupancy), GET /facilities/space-utilisation/:spaceId (utilisation trend), GET /facilities/space-utilisation/underused (spaces consistently below 50% utilisation — opportunities for consolidation).
  5. SustainabilityService — CRUD for initiatives. GET /facilities/sustainability/dashboard (active initiatives with progress).
UI
  1. Fire Drill Log /facilities/fire-drills — drill history per building. Compliance status (green=recent, rose=overdue). Log new drill with evacuation timer.
  2. Asset Lifecycle Manager /facilities/assets — asset registry with status pills. Per-asset: maintenance history, warranty status, replacement planning. Decommission + disposal workflow.
  3. Energy Dashboard /facilities/energy — consumption charts per meter. Actual vs target gauges. Cost trending. Annual comparison.
  4. Space Utilisation /facilities/utilisation — heatmap: rooms × periods with utilisation rate colour coding. Underused space report.
Produces → P2-18b: 10 tables, ~22 endpoints, 1 Kafka emit. Create all peer review docs. Total P2-18: 21 tables, ~46 endpoints.
