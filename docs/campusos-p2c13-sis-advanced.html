CampusOS · Phase 2 · Wave C — Operational Depth

P2-13: SIS Advanced

Student profiles with avatar approval workflow, school-defined custom fields with typed values attached to any SIS entity, graduation requirements with nightly credit audit and at-risk alerting, service learning hours with supervisor verification, GPA calculation configurations with weighted/unweighted/subject-area modes, official transcript generation with course history and credit summaries, student transfer records with records package tracking, locker assignment management, and parent-initiated information update requests with configurable auto-approval. The most-requested SIS features by registrars. Pre-split into 3 sub-cycles.
May 2026 · 3 Sub-Cycles · ERD v11 · M20 SIS .1 (24 tables) · STU-001..008 · Phase 2 Cycle 13

Sub-Cycle Structure

24 tables split into 3 independently shippable sub-cycles along functional boundaries: student identity + custom fields, graduation + service learning + GPA, and transcripts + transfers + lockers.

P2-13a — Student Profiles + Custom Fields + Parent Updates (8 tables)

Student-editable profiles with avatar approval, school-defined custom fields with typed values (TEXT, NUMBER, DATE, ENUM, MULTI_SELECT) attached to students/staff/guardians, and parent-initiated information update requests with configurable auto-approval for low-risk fields.

P2-13b — Graduation + Service Learning + GPA (8 tables)

Graduation requirement definitions (credit total, subject credit, specific course, service hours, assessment, minimum GPA), nightly graduation audit worker with per-student requirement-by-requirement status, service learning hours with supervisor verification and grade-level requirements, GPA calculation configurations (weighted, unweighted, subject-area), and course prerequisites.

P2-13c — Transcripts + Transfers + Lockers (8 tables)

Official transcript generation with course history, credit summaries, and GPA snapshot, transcript request workflow with fee collection, student transfer records with sending/receiving school tracking and records package management, locker assignment with combination encryption and year-end bulk clear, and advanced reporting period configurations.

P2-13a: Student Profiles + Custom Fields + Parent Updates

01Schema (8 tables)
Schema
  1. sis_student_profiles — student_id UUID FK(sis_students) NOT NULL UNIQUE, bio TEXT (max 500), currently_reading TEXT, favourite_song TEXT, interests TEXT[], motto TEXT (max 200), avatar_s3_key TEXT, avatar_status TEXT DEFAULT 'PENDING_APPROVAL' 3-value CHECK (PENDING_APPROVAL, APPROVED, REJECTED), avatar_reviewed_by UUID FK, avatar_reviewed_at TIMESTAMPTZ. Avatar requires homeroom teacher approval. Student-owned: only the student can edit bio/interests/motto.
  2. sis_custom_field_definitions — school_id UUID NOT NULL, entity_type TEXT NOT NULL 4-value CHECK (STUDENT, STAFF, GUARDIAN, CLASS), field_name TEXT NOT NULL, field_label TEXT NOT NULL, field_type TEXT NOT NULL 6-value CHECK (TEXT, NUMBER, DATE, BOOLEAN, ENUM, MULTI_SELECT), enum_options TEXT[] (for ENUM/MULTI_SELECT), is_required BOOLEAN DEFAULT false, is_visible_to_parent BOOLEAN DEFAULT false, sort_order INT DEFAULT 0, is_active BOOLEAN DEFAULT true. UNIQUE(school_id, entity_type, field_name). Schools define their own fields without schema changes.
  3. sis_custom_field_values — definition_id UUID FK NOT NULL, entity_id UUID NOT NULL (the student/staff/guardian/class this value belongs to), value_text TEXT, value_number NUMERIC(12,4), value_date DATE, value_boolean BOOLEAN, value_enum TEXT, value_multi TEXT[]. UNIQUE(definition_id, entity_id). INDEX(definition_id, entity_id). Only one value_* column populated per row based on field_type.
  4. sis_parent_info_update_requests — school_id UUID NOT NULL, submitted_by UUID FK NOT NULL, target_type TEXT NOT NULL 3-value CHECK (STUDENT_INFO, GUARDIAN_INFO, EMERGENCY_CONTACT), target_id UUID NOT NULL, proposed_changes JSONB NOT NULL, change_reason TEXT, status TEXT NOT NULL DEFAULT 'PENDING' 4-value CHECK (PENDING, APPROVED, REJECTED, AUTO_APPROVED), reviewed_by UUID FK, reviewed_at TIMESTAMPTZ, reviewer_notes TEXT, applied_at TIMESTAMPTZ. INDEX(school_id, status) WHERE status='PENDING'. On APPROVED: apply proposed_changes to target table, stamp applied_at, write audit_log.
  5. sis_auto_approval_rules — school_id UUID NOT NULL, target_type TEXT NOT NULL, field_name TEXT NOT NULL, auto_approve BOOLEAN NOT NULL DEFAULT false. UNIQUE(school_id, target_type, field_name). Low-risk fields (phone, email) can be auto-approved; high-risk (address, emergency contacts) require manual review.
  6. sis_student_photos — student_id UUID FK NOT NULL, photo_type TEXT NOT NULL 3-value CHECK (OFFICIAL, YEARBOOK, ID_CARD), s3_key TEXT NOT NULL, academic_year TEXT NOT NULL, is_current BOOLEAN DEFAULT true. UNIQUE(student_id, photo_type, academic_year). Official school photo vs student-uploaded avatar (on sis_student_profiles).
  7. sis_student_notes — student_id UUID FK NOT NULL, author_id UUID FK NOT NULL, note_type TEXT NOT NULL 5-value CHECK (ACADEMIC, BEHAVIOURAL, PASTORAL, ADMINISTRATIVE, CONFIDENTIAL), note_text TEXT NOT NULL, is_visible_to_parent BOOLEAN DEFAULT false, is_confidential BOOLEAN DEFAULT false. INDEX(student_id, note_type, created_at DESC). CONFIDENTIAL notes visible only to author + admin.
  8. sis_family_relationships — family_id UUID NOT NULL, guardian_a_id UUID FK NOT NULL, guardian_b_id UUID FK NOT NULL, relationship_type TEXT NOT NULL 6-value CHECK (MARRIED, DIVORCED, SEPARATED, COHABITING, STEP_PARENT, OTHER), custody_arrangement TEXT 4-value CHECK (JOINT, SOLE_A, SOLE_B, OTHER) nullable, notes TEXT. UNIQUE(family_id, guardian_a_id, guardian_b_id). CHECK(guardian_a_id != guardian_b_id). Custody arrangement drives which parent sees what data.
Produces → 8 tables. Migration: 128_sis_profiles_customfields.sql.

P2-13b: Graduation + Service Learning + GPA

03Schema (8 tables)
Schema
  1. sis_graduation_requirements — school_id UUID NOT NULL, requirement_type TEXT NOT NULL 6-value CHECK (CREDIT_TOTAL, SUBJECT_CREDIT, SPECIFIC_COURSE, SERVICE_HOURS, ASSESSMENT, MINIMUM_GPA), subject_area TEXT, credits_required NUMERIC(4,2), specific_course_id UUID, hours_required INT, assessment_name TEXT, minimum_gpa NUMERIC(3,2), is_active BOOLEAN DEFAULT true. INDEX(school_id, is_active).
  2. sis_student_graduation_audits — student_id UUID FK NOT NULL, requirement_id UUID FK NOT NULL, status TEXT NOT NULL 3-value CHECK (MET, IN_PROGRESS, NOT_MET), credits_earned NUMERIC(4,2), credits_remaining NUMERIC(4,2), detail TEXT, last_calculated TIMESTAMPTZ NOT NULL. UNIQUE(student_id, requirement_id). Materialised nightly by GraduationAuditWorker. Emits sis.graduation.at_risk when any senior has NOT_MET requirements.
  3. sis_service_learning_requirements — school_id UUID NOT NULL, grade_level TEXT NOT NULL, required_hours INT NOT NULL, deadline_type TEXT NOT NULL 3-value CHECK (END_OF_YEAR, BEFORE_GRADUATION, SPECIFIC_DATE), specific_deadline DATE, is_active BOOLEAN DEFAULT true. UNIQUE(school_id, grade_level).
  4. sis_service_learning_hours — student_id UUID FK NOT NULL, organisation_name TEXT NOT NULL, activity_description TEXT NOT NULL, hours NUMERIC(5,2) NOT NULL, service_date DATE NOT NULL, supervisor_name TEXT, supervisor_contact TEXT, evidence_s3_key TEXT, status TEXT DEFAULT 'PENDING' 3-value CHECK (PENDING, APPROVED, REJECTED), reviewed_by UUID FK, reviewed_at TIMESTAMPTZ. INDEX(student_id, status).
  5. sis_gpa_configurations — school_id UUID NOT NULL, config_name TEXT NOT NULL, calculation_method TEXT NOT NULL 3-value CHECK (UNWEIGHTED, WEIGHTED, SUBJECT_AREA), scale_type TEXT NOT NULL 2-value CHECK (FOUR_POINT, HUNDRED_POINT), grade_point_mapping JSONB NOT NULL (e.g., {"A+":4.0, "A":4.0, "A-":3.7, "B+":3.3...}), honors_weight_bonus NUMERIC(2,1) DEFAULT 0.5, ap_weight_bonus NUMERIC(2,1) DEFAULT 1.0, is_default BOOLEAN DEFAULT false. UNIQUE(school_id, config_name).
  6. sis_student_gpa_snapshots — student_id UUID FK NOT NULL, gpa_config_id UUID FK NOT NULL, academic_year_id UUID FK, term_id UUID FK, cumulative_gpa NUMERIC(4,3), term_gpa NUMERIC(4,3), total_credits_attempted NUMERIC(5,2), total_credits_earned NUMERIC(5,2), class_rank INT, class_size INT, calculated_at TIMESTAMPTZ NOT NULL. UNIQUE(student_id, gpa_config_id, academic_year_id, term_id). Materialised by GPAWorker at end of each term.
  7. sis_course_prerequisites — course_id UUID FK(sis_courses) NOT NULL, prerequisite_course_id UUID FK(sis_courses) NOT NULL, is_mandatory BOOLEAN DEFAULT true, min_grade TEXT. UNIQUE(course_id, prerequisite_course_id). CHECK(course_id != prerequisite_course_id).
  8. sis_grade_scale_entries — school_id UUID NOT NULL, scale_name TEXT NOT NULL, letter_grade TEXT NOT NULL, min_percentage NUMERIC(5,2), max_percentage NUMERIC(5,2), grade_points NUMERIC(3,1), is_passing BOOLEAN DEFAULT true. UNIQUE(school_id, scale_name, letter_grade). The school's grade-to-percentage mapping.
Produces → 8 tables. Migration: 129_sis_graduation_gpa.sql.

SeedCodeUITest
Seed
  1. 6 graduation requirements (CREDIT_TOTAL 24 credits, SUBJECT_CREDIT English 4 credits, SPECIFIC_COURSE US History, SERVICE_HOURS 40 hours, ASSESSMENT SAT, MINIMUM_GPA 2.0). 10 graduation audits across 3 students (2 MET, 5 IN_PROGRESS, 3 NOT_MET). 1 service learning requirement (Grade 12, 40 hours). 5 service learning hours (3 APPROVED, 1 PENDING, 1 REJECTED). 2 GPA configs (UNWEIGHTED 4-point, WEIGHTED 4-point with AP/honors bonus). 6 GPA snapshots across 3 students. 3 course prerequisites. 1 grade scale (A+ through F).
Services (~20 endpoints)
  1. GraduationService — CRUD for requirements. GET /sis/students/:id/graduation-audit (per-student requirement checklist). GraduationAuditWorker: nightly for all seniors: computes credits earned per subject from cls_grades, checks service hours, checks GPA, upserts sis_student_graduation_audits. Emits sis.graduation.at_risk for students with NOT_MET.
  2. ServiceLearningService — POST /sis/service-learning (student submits with evidence), GET /sis/students/:id/service-learning, PATCH /sis/service-learning/:id (admin approves/rejects). GET /sis/service-learning/progress (school-wide: hours completed vs required by grade).
  3. GPAService — CRUD for GPA configs + grade scales. GET /sis/students/:id/gpa (cumulative + term + rank). GPAWorker: end-of-term for all students: computes GPA from cls_grades using configured grade_point_mapping + weight bonuses, ranks within grade level, upserts snapshots.
  4. PrerequisiteService — CRUD for prerequisites. GET /sis/courses/:id/prerequisites. POST /sis/course-registration/validate (checks student has completed prerequisites with min_grade before allowing enrolment).
UI
  1. Graduation Tracker /sis/graduation — admin: school-wide at-risk list. Student/parent: per-student requirement checklist with MET/IN_PROGRESS/NOT_MET pills + credits remaining.
  2. Service Learning /sis/service-learning — student: submit hours form. Admin: approval queue. Progress dashboard by grade.
  3. GPA Dashboard (inline on student academic profile) — cumulative + term GPA chart. Class rank. Weighted vs unweighted comparison.

P2-13c: Transcripts + Transfers + Lockers

05Schema (8 tables)
Schema
  1. sis_transcripts — student_id UUID FK NOT NULL, transcript_type TEXT NOT NULL 2-value CHECK (OFFICIAL, UNOFFICIAL), generated_at TIMESTAMPTZ NOT NULL, generated_by UUID FK NOT NULL, gpa_config_id UUID FK NOT NULL, cumulative_gpa_snapshot NUMERIC(4,3), total_credits NUMERIC(5,2), class_rank INT, class_size INT, pdf_s3_key TEXT, status TEXT NOT NULL DEFAULT 'GENERATED' 3-value CHECK (GENERATED, SENT, REVOKED). INDEX(student_id, generated_at DESC).
  2. sis_transcript_courses — transcript_id UUID FK NOT NULL, academic_year TEXT NOT NULL, term TEXT NOT NULL, course_name TEXT NOT NULL, course_code TEXT, credits NUMERIC(3,1), grade TEXT NOT NULL, grade_points NUMERIC(3,1), is_honors BOOLEAN DEFAULT false, is_ap BOOLEAN DEFAULT false. INDEX(transcript_id). Snapshot of course history at generation time — frozen, not live-joined.
  3. sis_transcript_requests — student_id UUID FK NOT NULL, requested_by UUID FK NOT NULL, recipient_name TEXT NOT NULL, recipient_address TEXT, recipient_email TEXT, transcript_type TEXT NOT NULL 2-value CHECK (OFFICIAL, UNOFFICIAL), copies INT NOT NULL DEFAULT 1, fee_amount NUMERIC(6,2), fee_paid BOOLEAN DEFAULT false, linked_invoice_id UUID (soft to pay_invoices), status TEXT NOT NULL DEFAULT 'SUBMITTED' 5-value CHECK (SUBMITTED, PROCESSING, SENT, PICKED_UP, CANCELLED). INDEX(student_id, status).
  4. sis_transfer_records — student_id UUID FK NOT NULL, transfer_direction TEXT NOT NULL 2-value CHECK (INCOMING, OUTGOING), other_school_name TEXT NOT NULL, other_school_country TEXT, transfer_date DATE NOT NULL, records_received BOOLEAN DEFAULT false, records_sent BOOLEAN DEFAULT false, records_package_s3_key TEXT, notes TEXT. INDEX(student_id, transfer_date).
  5. sis_lockers — school_id UUID NOT NULL, locker_number TEXT NOT NULL, location_description TEXT, combination_encrypted TEXT (AES-256), status TEXT DEFAULT 'AVAILABLE' 3-value CHECK (AVAILABLE, ASSIGNED, OUT_OF_SERVICE), assigned_to_student_id UUID FK, assigned_at DATE, academic_year TEXT. UNIQUE(school_id, locker_number). INDEX(school_id, status) WHERE status='AVAILABLE'.
  6. sis_reporting_periods — school_id UUID NOT NULL, academic_year_id UUID FK NOT NULL, name TEXT NOT NULL, period_type TEXT NOT NULL 4-value CHECK (PROGRESS_REPORT, REPORT_CARD, INTERIM, FINAL), start_date DATE NOT NULL, end_date DATE NOT NULL, grades_due_date DATE NOT NULL, comments_due_date DATE, status TEXT NOT NULL DEFAULT 'UPCOMING' 4-value CHECK (UPCOMING, OPEN, GRADING_CLOSED, PUBLISHED). UNIQUE(school_id, academic_year_id, name).
  7. sis_student_awards — student_id UUID FK NOT NULL, award_type TEXT NOT NULL 6-value CHECK (HONOR_ROLL, DEANS_LIST, PERFECT_ATTENDANCE, SUBJECT_AWARD, CITIZENSHIP, OTHER), award_name TEXT NOT NULL, academic_year TEXT, term TEXT, awarded_by UUID FK, certificate_s3_key TEXT. INDEX(student_id, academic_year).
  8. sis_medical_exemption_records — student_id UUID FK NOT NULL, exemption_type TEXT NOT NULL 4-value CHECK (PE, SWIMMING, FIELD_TRIP, OTHER), reason TEXT NOT NULL, doctor_note_s3_key TEXT, effective_from DATE NOT NULL, effective_to DATE, approved_by UUID FK. INDEX(student_id, effective_from).
Produces → 8 tables. Migration: 130_sis_transcripts_transfers.sql. Total P2-13 tables: 24.

SeedCodeUITest
Seed

Services (~20 endpoints)
  1. TranscriptService — POST /sis/students/:id/transcripts/generate (snapshots all course grades + GPA + rank into sis_transcript_courses; generates PDF), GET /sis/students/:id/transcripts, POST /sis/transcript-requests (parent/student requests; creates pay_invoice for fee if applicable), PATCH /sis/transcript-requests/:id (process: generate → send).

LockerService — GET /sis/lockers (admin: all with status), POST /sis/lockers/assign (assign to student + generate encrypted combination), POST /sis/lockers/:id/release, POST /sis/lockers/bulk-clear (year-end: release all assigned lockers). GET /sis/students/:id/locker (student: own locker + combination decrypted for display).
  4. ReportingPeriodService — CRUD + status transitions (UPCOMING → OPEN → GRADING_CLOSED → PUBLISHED). GET /sis/reporting-periods/current.
  5. StudentAwardService — CRUD. GET /sis/students/:id/awards. POST /sis/awards/bulk-honor-roll (auto-generate for students meeting GPA threshold).
UI
  1. Transcript Manager /sis/transcripts — admin: generate for student, request queue, send workflow. Student/parent: request form, download unofficial.
  2. Transfer Records /sis/transfers — admin: incoming/outgoing tracking with records package management.
  3. Locker Manager /sis/lockers — admin: locker grid by location, assign/release, year-end bulk clear. Student: own locker + combination.
  4. Awards /sis/awards — admin: bulk honor roll generation. Student: award history with certificates.
