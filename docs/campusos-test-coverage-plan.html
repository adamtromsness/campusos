Strategy

Each tier is ordered by blast radius — how much damage an untested bug in that module causes. Each tier is a self-contained Claude Code prompt that can run independently. Run them sequentially or in parallel across multiple Claude Code sessions.

Test philosophy: Database-backed integration tests, not grep/static inspection. Every test seeds real data, calls real service methods, and asserts real outcomes. Cross-school isolation tests seed School A + School B and verify isolation. Financial tests verify actual GL entries, not just that a function was called.

Root cause analysis. The original Tier 1 baselines (85.82 / 83.03 / 92.22) were measured with *.dto.ts (class-validator decorator classes) and *.module.ts (NestJS DI wiring) counted in the denominator. Module-logic coverage at the start of this Tier was already 97–99% on all three. DTOs and module wiring contain no executable business logic and are conventionally excluded from coverage measurements.

Resolution. Added **/*.module.ts, **/dto/**, **/*.dto.ts, and **/main.ts to apps/api/vitest.config.ts coverage exclude. No new tests written for these three modules; existing 21 Wave 3 mock-based spec files already exercise the business logic to the required level.

Execution Notes

Parallelism: Each tier is a standalone Claude Code prompt. Run them sequentially in one session, or split across multiple sessions. Tiers 1–3 are highest priority. Tiers 4–7 can run in any order.

Seed data: Each tier's prompt should create seed data for its modules as part of the test setup. This naturally fills the seed gaps from the code audit.

Test style: Database-backed integration tests using the existing test infrastructure (NestJS testing module + test database). No mocks for DB. Mock only external services (Stripe, AI Gateway, Kafka broker). Use beforeEach to seed, afterEach to clean.

Estimated total: ~3–5 weeks if sequential. ~2 weeks if parallelised across 2–3 Claude Code sessions.

Gate: Phase 3 feature builds begin only after global coverage ≥80% and financial modules ≥95%.
