Cycle 24: Student Portfolio

Student-owned digital portfolios with multi-source item collection (classroom submissions, grades, achievements, reflections, external files, certificates), 4-tier visibility controls (PRIVATE / TEACHER / PARENT / PUBLIC), time-limited share links with view tracking, cross-module achievements from every prior cycle, and achievement sharing to external platforms. The fourth student-input surface — students curate their own academic narrative.
May 2026 · 8 Steps · ERD v11 · M26 Portfolio (5 tables — all in scope) · ACH-001 + ACH-002

Plan Overview

Cycle 24 builds the M26 Portfolio module — all 5 ERD tables. This is the most compact module in the entire build (5 tables) but architecturally significant because it is the first student-owned surface: students create, curate, and control their portfolio. Every prior student-input surface (wellbeing check-ins, reading logs, club registration, service hours) wrote into staff-administered systems. The portfolio belongs to the student — they control what goes in, what's featured, and who can see it.

The module is a cross-system aggregation layer. pfl_portfolio_items.source_ref_id is a DISPLAY-ONLY polymorphic reference that can point to cls_submissions (Cycle 2), cls_grades (Cycle 2), or pfl_achievements. Achievements themselves aggregate from every prior module: reading programme completions (Cycle 12's lib_programme_completions.achievement_id), community service milestones (Cycle 17), athletics records (Cycle 13), and teacher-awarded commendations. The portfolio is the student's unified view of their entire CampusOS journey.

Vertical Slice Deliverable

Maya creates her portfolio "Maya's Academic Journey" (visibility=TEACHER) → adds her top-graded narrative writing submission from Cycle 2 (item_type=SUBMISSION, source_ref_id=cls_submissions.id) → adds her Grade 5 ELA final grade (item_type=GRADE) → writes a personal reflection on her growth in writing (item_type=REFLECTION) → marks the submission as featured → teacher Rivera awards Maya an ACADEMIC achievement "Outstanding Writer" with a badge image → the Cycle 12 reading programme completion auto-creates a COMMUNITY achievement via the lib_programme_completions.achievement_id soft FK → Maya adds both achievements to her portfolio → Maya upgrades portfolio visibility to PARENT so David Chen can see it → Maya generates a share link (32-byte token, expires in 30 days) and emails it to a family member → the family member views the portfolio via the share link (viewed_at tracked) → Maya shares her "Outstanding Writer" achievement to an external platform (EMAIL) → on student transfer, visibility auto-resets to PRIVATE.

Step-by-Step Build Plan

01Portfolio + Items + Shares Schema
Schema

Student portfolios with 4-tier visibility, polymorphic portfolio items sourcing from classroom submissions, grades, achievements, reflections, and external files, and time-limited share links with view tracking.

Tables (3)
  1. pfl_portfolios — student_id UUID NOT NULL (soft to platform_entity_cache), school_id UUID, title TEXT NOT NULL, description TEXT, visibility TEXT NOT NULL DEFAULT 'PRIVATE' 4-value CHECK (PRIVATE, TEACHER, PARENT, PUBLIC), share_link_enabled BOOLEAN DEFAULT false. INDEX(student_id, school_id). On student transfer or graduation: visibility auto-resets to PRIVATE.
  2. pfl_portfolio_items — portfolio_id UUID FK NOT NULL, item_type TEXT NOT NULL 6-value CHECK (SUBMISSION, GRADE, ACHIEVEMENT, REFLECTION, EXTERNAL_FILE, CERTIFICATE), source_ref_id UUID nullable (DISPLAY-ONLY polymorphic: cls_submissions, cls_grades, or pfl_achievements — no DB FK), title TEXT NOT NULL, description TEXT, s3_key TEXT nullable (for EXTERNAL_FILE + CERTIFICATE types), is_featured BOOLEAN DEFAULT false, added_at TIMESTAMPTZ NOT NULL. INDEX(portfolio_id, is_featured, added_at DESC).
  3. pfl_portfolio_shares — portfolio_id UUID FK NOT NULL, share_token TEXT NOT NULL UNIQUE (32-byte random hex), expires_at TIMESTAMPTZ nullable (null = no expiry), recipient_email TEXT, viewed_at TIMESTAMPTZ nullable, status TEXT NOT NULL DEFAULT 'ACTIVE' 3-value CHECK (ACTIVE, EXPIRED, REVOKED). Partial INDEX(expires_at) WHERE expires_at IS NOT NULL for the cleanup job. Expired tokens return 410 Gone.
Produces → 3 new tables. Migration: 075_pfl_portfolios.sql.
02Achievements + Achievement Shares Schema
Schema

Cross-module achievements aggregating from every prior cycle, and achievement sharing to external platforms.

Tables (2)
  1. pfl_achievements — student_id UUID NOT NULL (soft to platform_entity_cache), school_id UUID, title TEXT NOT NULL, achievement_type TEXT NOT NULL 6-value CHECK (ACADEMIC, SPORTING, MUSICAL, LEADERSHIP, COMMUNITY, CUSTOM), source_module TEXT nullable (DISPLAY-ONLY: "library", "athletics", "clubs", "classroom", etc.), source_ref_id UUID nullable (DISPLAY-ONLY: lib_programme_completions.id, ath_all_time_records.id, ext_service_progress.id, etc. — intentionally portable, no DB FK), awarded_at DATE NOT NULL, awarded_by UUID FK nullable (teacher/staff who awarded; null for system-generated), description TEXT, badge_image_url TEXT. INDEX(student_id, school_id). Achievements are intentionally portable and independent of source module.
  2. pfl_achievement_shares — achievement_id UUID FK NOT NULL, shared_by UUID FK NOT NULL (soft to platform_users — the student), platform TEXT NOT NULL 3-value CHECK (EMAIL, SOCIAL, PORTFOLIO), shared_at TIMESTAMPTZ NOT NULL. INDEX(achievement_id, shared_at DESC).
Produces → 2 new tables. Migration: 076_pfl_achievements.sql. Total Cycle 24 tables: 5.

  5. Permissions: ACH-001:read to Student (view own achievements), ACH-001:write to Teacher, Staff (award achievements). ACH-002:read to Student (view own + TEACHER/PARENT-visible others per scope), Teacher, Parent (view student portfolios per visibility). ACH-002:write to Student (own portfolio CRUD), Teacher (annotate). Admin gets all via everyFunction.
Produces → Portfolio + items + achievements seeded with cross-module source references. ACH-001..002 permissions.
04Portfolio NestJS Module
Code
Services & Endpoints
  1. PortfolioService — GET /portfolio/my (STUDENT-OWNED: returns the calling student's portfolio with items + achievements inlined), GET /portfolio/students/:studentId (teacher/parent: visibility-gated; PRIVATE returns 404 for non-owner; TEACHER visible to teachers; PARENT visible to parents + teachers; PUBLIC visible to all), POST /portfolio (student creates; one portfolio per student per school enforced), PATCH /portfolio/:id (student updates title, description, visibility; owner-only).
  2. PortfolioItemService — GET /portfolio/:id/items (with source resolution: SUBMISSION items resolve title from cls_submissions; GRADE items resolve from cls_grades; ACHIEVEMENT items resolve from pfl_achievements), POST /portfolio/:id/items (student adds; validates source_ref_id resolves in tenant when source-typed), PATCH /portfolio-items/:id (student edits title, description, is_featured; owner-only), DELETE /portfolio-items/:id (student removes; owner-only). GET /portfolio/:id/items/sources (student: list available items to add from classroom + achievements).
  3. ShareService — POST /portfolio/:id/shares (student generates share link; 32-byte random token; optional expires_at + recipient_email), GET /portfolio/share/:token (public unauthenticated endpoint; validates token active + not expired; stamps viewed_at on first view; returns portfolio + featured items; expired returns 410 Gone), DELETE /portfolio-shares/:id (student revokes; status → REVOKED).
Produces → PortfolioModule with 3 services, ~12 endpoints.
05Achievements NestJS Module
Code
Services & Endpoints
  1. AchievementService — GET /portfolio/achievements (student: own; teacher: scope-visible students), GET /portfolio/achievements/:id (with source module + source ref resolution), POST /portfolio/achievements (teacher awards to student; emits pfl.achievement.awarded), PATCH /portfolio/achievements/:id (teacher edits own award; student cannot edit teacher-awarded). GET /portfolio/students/:studentId/achievements (all achievements for a student, grouped by type).
  2. AchievementShareService — POST /portfolio/achievements/:id/share (student shares own achievement to EMAIL/SOCIAL/PORTFOLIO), GET /portfolio/achievements/:id/shares (student: share history).
Produces → 2 services, ~8 endpoints, 1 Kafka emit (pfl.achievement.awarded). Total Cycle 24 endpoints: ~20.
06Portfolio UI — Student Portfolio Builder + Public View
UI
Pages
  1. Portfolio Dashboard /portfolio — "Portfolio" app tile gated on ACH-002:read. Student view: my portfolio with item count + achievement count + visibility pill + "Edit Portfolio" button. Teacher view: student portfolios for my classes (visibility-gated). Parent view: child's portfolio (when PARENT or PUBLIC visibility).
  2. Portfolio Builder /portfolio/edit — STUDENT-OWNED. Title + description editor. Visibility selector (PRIVATE/TEACHER/PARENT/PUBLIC) with explanations. Item list with drag-reorder + feature toggle (star icon). 07Portfolio UI — Achievements + Teacher Award + Parent View
UI
Pages
  1. Achievement Gallery /portfolio/achievements — student: all achievements grouped by type (ACADEMIC/SPORTING/MUSICAL/LEADERSHIP/COMMUNITY/CUSTOM) with badge images + dates + source module pills. Share button per achievement.

08Vertical Slice Integration Test
Test
Test Script
  1. Portfolio creation (student-owned): Maya creates portfolio (PRIVATE). Verify one-per-student UNIQUE. Ethan cannot access Maya's PRIVATE portfolio (404).
  2. Item sourcing from Cycle 2: Maya adds a cls_submission item (SUBMISSION type). Verify source_ref_id resolves to the Cycle 2 submission title. Maya adds a cls_grades item (GRADE type).

  8. Cross-module achievement (Cycle 12): Verify the seeded lib_programme_completions.achievement_id resolves to the pfl_achievements row. The achievement shows source_module=library in the gallery.
  9. Achievement sharing: Maya shares "Outstanding Writer" via EMAIL. Verify pfl_achievement_shares row created.
  10. Visibility + ownership: Teacher cannot edit Maya's portfolio items. Student cannot award achievements. Parent sees portfolio read-only. Verify transfer privacy reset: simulate transfer → visibility resets to PRIVATE.
